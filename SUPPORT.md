# Support

Relay Runner is an early open-source project without a paid support SLA.

## Questions and bug reports

1. Check [Troubleshooting](docs/troubleshooting.md) and the [existing issues](https://github.com/matthewthomas94/relay-runner/issues).
2. If the problem remains, [open an issue](https://github.com/matthewthomas94/relay-runner/issues/new) with the Relay Runner version, macOS version, provider, expected behavior, actual behavior, and the smallest safe reproduction.
3. Remove usernames, personal paths, repository content, voice transcripts, tokens, and credentials from screenshots and logs before posting.

Provider authentication, account access, billing, model availability, and provider outages belong to [OpenAI support](https://help.openai.com/) or [Anthropic support](https://support.anthropic.com/) when Relay Runner is only surfacing the upstream response.

For a suspected vulnerability, follow [SECURITY.md](SECURITY.md) and report it privately instead of opening a public issue.
