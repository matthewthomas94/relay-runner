# Relay Runner 0.4.50

## New model support

- Added GPT-6 Astra and explicit Claude Fable 5.1 selections across foreground configuration, Messenger, and worker overrides.
- Astra resolves through the configured Codex model catalog, including supported reasoning efforts. Explicit Astra workers support Max and Ultra when advertised by that CLI.
- Fable 5.1 uses the exact `claude-fable-5-1` identifier. Existing model aliases, saved defaults, and worker-tier mappings remain unchanged.

## Voice and session reliability

- Improved Messenger response latency and attribution to the correct provider turn.
- Fixed handoff acknowledgements suppressing authoritative final answers.
- Synchronized playback previews, speech readiness, and replay with the accepted response identity.
- Fixed queued voice commands becoming stranded after an app-owned provider replacement.
- Required terminal-submission evidence before treating a provider continuation as a manual turn.
- Isolated replay test fixtures from live voice sockets.

## Work orchestration

- Improved the distinction between informational ticket questions and authorized project changes.
- Removed the automatic five-attempt retry cap; existing cancellation and verification-blocker handling remain in place.

## Compatibility and verification

Requires macOS 14 or later. Model access depends on provider account eligibility and a compatible CLI; a model-picker entry does not grant access. Codex 0.153.4 bundled with ChatGPT advertised Astra during verification; the older PATH CLI 0.151.0 did not.

Source tests cover both providers. Installed Codex voice checks and user acceptance are recorded in the repository; separate Claude live checks were not independently verified for every fix. No existing saved model defaults are changed by this release.
