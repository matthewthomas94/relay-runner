## Description

With one app-owned session that reaches every registered project, the per-project session surfaces go:

- The Start/End buttons on project cards or rows, and the `startSession(projectPath:)` / `endSession(projectPath:)` paths in `Sources/relay-runner/Board/ProgramBoardOverlayController.swift`.
- Per-session terminal tabs (`workspaceSessionTabs` at `Sources/relay-runner/App/AppState.swift:1345`, `closeSessionTab` at `:1430`).
- The session wheel's project picker and more-sessions slots (`SessionWheelModel.showProjects` at `Sources/relay-runner/Board/SessionWheelModel.swift:352`, `sessionWheel.startProject` at `AppState.swift:1033`). The wheel keeps its controls and shortcuts, and its centre still closes it.
- `activate_project` keeps working as board navigation and filtering; it no longer starts or focuses a per-project session.

Add one Start/End control at the far right of the Workspace top row, opposite the Workspace, Notetaker and Settings tabs (`WorkspaceMenuBarStrip` in `Sources/relay-runner/Board/WorkspaceOverlayShell.swift:121`, laid out with space between). Use the existing solid white, black-text primary style (`ProgramSessionPrimaryButton` in `Sources/relay-runner/Board/ProgramBoardOverlayView.swift`) and the existing titles from `ProgramSessionToolbarPresentation` (Start Claude, Start Codex, End ...). Start launches the general session; End ends it.

Remove multi-session code in `EmbeddedSessionRegistry` and `AppState` only where it is clearly dead after this change; otherwise leave it and note it in the run log. Update `SessionWheelTests`, `ProgramBoardOverlayControllerTests`, `AssistantContextLifecycleTests` and related suites. Keep the source contract that Workspace buttons never use `prominence: .primary`; `ProgramSessionPrimaryButton` does not.
