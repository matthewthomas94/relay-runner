## Description

Implement and evaluate the same Task / Action / Discussion framework with local Laya on a dedicated experimental branch, codex/laya-intent-qualification. The user specifically wants branch-isolated testing; do not merge the Laya dependency or behavior into main. This is a writable implementation experiment, not a branchless read-only spike. Coordinate with the baseline framework ticket and reuse its taxonomy, labelled corpus and command-identity contract.

## Acceptance criteria

- [ ] A reproducible optional local Laya adapter uses fixed-choice qualification with compact relevant context, explicit checkpoint/runtime versions and no cloud API dependency. Runtime/model downloads happen during explicit setup, never on a voice command. Keep weights and environments outside tracked source.
- [ ] Compare English and multilingual checkpoints where locally feasible, using the same inputs and definitions as the existing-workflow baseline. Do not assume the upstream language router chooses the most accurate intent model. Start zero-shot; record whether fine-tuning is justified rather than silently claiming accuracy.
- [ ] Add a read-only evaluation command that records per-case classification, per-class confusion, false Task/Action decisions, fallback rate, cold load separately, warm p50/p95 and actual machine/runtime/checkpoint identity. Qualification includes tokenization and result formatting; MLX execution must be synchronized. Calibration/development cases and held-out cases are separate. No test utterance executes an email, ticket, shell or desktop action.
- [ ] A branch-only workflow test mode runs Laya as a bounded local qualification hint while Messenger starts immediately and PM retains the full original request and authority. Missing runtime, model error, timeout, truncation, unresolved references or mixed intent must fall back without blocking command delivery or creating mutation authority. Preserve stop/cancel, accepted-work continuity and stale-command checks for Codex and Claude.
- [ ] Treat confidence as an uncalibrated model signal until RR evidence establishes otherwise. Explicit negation/correction cases are mandatory; do not allow a high score to bypass discussion-only instructions. Test the documented cancellation failure family.
- [ ] Run actual local model inference if setup can be safely provisioned; otherwise report the exact external setup blocker and deliver runnable commands without fabricating benchmark results. Proposed warm added-latency target is p95 <=100 ms; report measured performance even if it misses the target.
- [ ] Commit source, repeatable commands and honest experiment results on codex/laya-intent-qualification. Include how to start a separate test session, compare with the baseline, and revert. Preserve main, unrelated dirty note work and the installed app; no production installation or automatic merge.
