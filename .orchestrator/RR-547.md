## Description

The user does not read the transcript inside a selected note any more, and wants to copy it instead. This also frees the panel for the note chat that follows in a later ticket.

**Today:** `ProgramNoteDetailPanel` (`Sources/relay-runner/Board/ProgramBoardOverlayView.swift`, around line 2749) shows the note's Summary and then the full Transcript inside one `BoardOverlayScrollView` (around lines 2970-2990). Its action row has Delete, Copy note (copies the whole Markdown through `ProgramBoardNoteDetail.copyNote`), Reveal and the recovery and retry buttons.

Scope:
- Remove the Transcript section from the note detail panel. Keep the Summary and the "Opening note…" loading state. Keep loading `detail.transcript`, because Copy transcript and the note chat need it.
- Add a **Copy transcript** button to the action row, next to Copy note, using `ProgramDetailActionButton` and the Lucide copy-style icon that best tells it apart from Copy note. It copies only the transcript text (`ProgramBoardNoteDetail.transcript`) to the general pasteboard.
- It is disabled while the note is loading or when the transcript is missing or empty, with help text that says why ("No transcript yet").
- Add `canCopyTranscript` / `copyTranscript(to:)` to `ProgramBoardNoteDetail` in `Sources/relay-runner/Board/ProgramBoardStatus.swift`, mirroring `canCopyNote` / `copyNote(to:)`.
- When a note has no summary yet, the panel must not look broken: show the existing status label and nothing else in the body.

## Acceptance criteria

- [ ] A selected note no longer shows a Transcript section; the Summary still shows.
- [ ] Copy transcript copies exactly the transcript text, not the Markdown note, covered by a unit test against a private `NSPasteboard`.
- [ ] Copy transcript is disabled while loading and when the transcript is nil or empty, covered by a unit test.
- [ ] Copy note, Reveal, Delete, Retry summary and recovery buttons behave as before.
- [ ] `swift build` and the Notes and board test targets pass; the pre-existing `testSwiftAndShellWritersShareCrossProcessLock` failure is not counted.
