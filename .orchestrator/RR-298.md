## Description

Fix lifecycle outcome text being irreversibly truncated before it reaches the response pill. A mounted `run-verification-resumed` update for RR-279 rendered as `RR-279 verification resumed: Mounted test on the currently running installed Relay Runner v0....` under **Double tap Option to play**, even though the response pill already supports wrapped, scrollable long bodies.

The truncation happens upstream: `OrchestrationTraceEvent` applies the 96-character public trace limit to the only copy of the lifecycle message, then the daemon persists and delivers that shortened value to Messenger. Preserve the intentionally compact status/notch representation while carrying the complete public lifecycle detail through daemon persistence, Messenger realization, and the TTS display-preview path. Do not solve this by merely increasing the visual pill height or by removing privacy checks from public trace content.
