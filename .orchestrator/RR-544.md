## Description

Build the Settings tab, screen 27 (`docs/design/relay-remote-ios/README.md`, section "Settings tab"; image `27-settings.jpg`, which shows the full scroll length; Figma [2139:49386](https://www.figma.com/design/IGjwpE5m7vLaCThHgoy0cw/Relay-Runner?node-id=2139-49386)). Replace the placeholder `SettingsTabView` from RR-533, using its design-system components, the existing preferences, and the kit's settings API from RR-532 (`settings_command` `get` and `set`, pushed `settings_state`). The settings currently live in `ios/RelayRemote/DebugView.swift`; move what the design keeps.

**Sections, in the order and layout of the image. No page title. Subtitles are one short line or absent.**

- **Voice**
  - Remote mode (existing `RemoteModePreference` and `AppModel.remoteMode`).
  - Talk: a two-segment control, Hold / Toggle (the talk-mode preference from RR-533). There is no hands-free option.
  - Replies: Auto-play / Queue (existing `PlaybackModePreference`).
  - Reply notifications: a toggle bound to the reply-notifications preference from RR-533. Turning it on when iOS notification permission has not been decided requests it; when permission is denied, the toggle stays off and one line points to iOS Settings.
  - Speech speed: a slider from 0.5x to 2.0x in 0.1 steps showing the current value, read from and written to the Mac. It writes when the user lets go, not on every movement.
- **Orchestrator:** Model, Effort and Sub-agent sizing, each a row opening a choice of the options the Mac sent with their labels. Changing the model refreshes the effort options from the Mac's reply. These write to the Mac at once.
- **Mac:** the paired Mac's name and connection state, the running agents, and "Stop all" as a danger button, with a confirmation, which stops every running agent (existing session `stop`).
- **Pairing:** the Mac's fingerprint and "Forget this Mac" as a danger button, with a confirmation (existing `AppModel.forget()`); afterwards the app shows the pairing flow.

**States for the Mac-backed controls (speech speed and Orchestrator):** loading until the first `settings_state`; disabled with one short line when the Mac is unreachable; when a `set` is refused, the control returns to the Mac's value and one short line shows the error. A change made on the Mac while the screen is open updates the controls.
