## Description

Enhance command-bearing transcription/status pills by reusing the existing onboarding keycap animations as compact trailing affordances. Keep instruction text aligned at the far left and place the matching animated keycap at the far right inside the pill, with spacing that preserves the existing title/body hierarchy. Refactor the onboarding keycap animation view only as needed to support a reusable compact presentation rather than duplicating animation timing or assets. Map recording send instructions to Caps Lock, response playback to Option double-tap, playback cancellation to Control double-tap, and other command-bearing pill states to their matching existing onboarding animation. For the no-session pill, use the primary Option action as the trailing animation while retaining the Caps Lock dismissal text. Preserve Reduce Motion, accessibility, pill sizing, preview scrolling, and existing themes.

## Acceptance criteria

- [ ] A full recording pill showing the stop-and-send instruction renders compact animated Caps Lock artwork at the far-right edge, opposite the left-aligned text.
- [ ] A response-ready pill renders the compact Option double-tap animation, and an active-playback cancellation pill renders the compact Control double-tap animation.
- [ ] The no-session command pill uses the Option double-tap animation for its primary action while retaining both existing text instructions.
- [ ] The compact pill keycaps reuse the onboarding assets and shared animation phase/timing logic rather than maintaining a duplicate animation implementation.
- [ ] Keycap artwork is scaled to fit the pill without clipping, changing the intended pill corner treatment, obscuring text, or reducing body preview usability.
- [ ] Non-command pills render no keycap affordance and preserve their current layout.
- [ ] Reduce Motion shows an appropriate static emphasized keycap state, and accessibility exposes the instruction without redundantly announcing decorative artwork.
- [ ] Focused tests cover state-to-animation mapping, left/right pill layout, compact sizing, Reduce Motion, and no-keycap states; existing pill placement and onboarding animation tests continue to pass.
