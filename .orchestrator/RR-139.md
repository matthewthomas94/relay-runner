## Description

When the notch status surface expands, contracts, or shifts around hover-driven trace labels, the motion can feel abrupt. Add subtle easing to the notch expansion/collapse and trace-hover presentation so width, placement, and label changes feel intentional instead of snapping.

Preserve the stability work from the hover/trace fixes: easing should not reintroduce oscillation, repeated expand/contract loops, clipped labels, or delayed responsiveness.

## Acceptance criteria

- [ ] Hover expansion and collapse of the notch status surface use a subtle easing curve instead of abrupt geometry changes.
- [ ] Trace label width/placement changes ease smoothly while preserving readable text and avoiding overlap or clipping.
- [ ] Existing hover stability remains intact; the surface does not oscillate when trace/activity labels update.
- [ ] The interaction remains responsive and respects any existing reduced-motion or animation-disabling behavior in the app.
- [ ] Add focused regression coverage for the animation/placement policy where practical, or document a manual visual verification scenario in the run log.
