## Description

The project board does not show a total ticket count in each vertical/lane the way the Program Board does. Also, tickets cannot be scrolled all the way to the very top or very bottom in either board.

Bring the Project Board lane headers into visual parity with the Program Board by showing a lane count beside each lane title. Fix scroll extents for both boards so the first and last cards can be fully reached without being clipped under headers, rounded containers, bottom padding, or overlay chrome.

## Acceptance criteria

- [ ] Project Board lanes show the total count for each lane in the header, matching the Program Board pattern.
- [ ] Program Board lane counts continue to show the correct totals.
- [ ] In both boards, the top card in a lane can be scrolled fully into view.
- [ ] In both boards, the bottom card in a lane can be scrolled fully into view.
- [ ] Empty lane placeholders and add buttons do not alter scroll bounds incorrectly.
- [ ] Add or update Swift layout/model tests for lane counts and scrollable content sizing.
- [ ] Verify with `swift test --skip-update`.
