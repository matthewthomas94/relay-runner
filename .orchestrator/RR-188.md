## Description

Expose a clear Settings action for restarting the intro onboarding flow. `StatusSettingsTab` already contains a functional `Re-run Setup Walkthrough…` action, but it is buried in an untitled section after the runtime rows and is easy to miss. Turn that existing action into a discoverable, explicitly titled Onboarding section near the top of the default Status page.

Use the established Settings row treatment: a short label and description on the left and a `Redo Onboarding…` action on the right. The action must use the intro-only presentation path while leaving normal Settings content intact underneath. A manual redo on a completed installation must traverse the entire current onboarding flow, including workspace selection as the final step; preserve the existing focused upgrade path that intentionally skips workspace. Do not reset completion flags, permission grants, authentication, workspace, provider, model, or reasoning settings merely by displaying or pressing the button; those values may change only through the onboarding actions the user subsequently takes.

## Acceptance criteria

- [ ] The default Status page has a titled `Onboarding` section near the top, before permission/runtime management.
- [ ] The section explains that the intro can be run again and exposes a clearly labeled `Redo Onboarding…` button.
- [ ] Pressing the button presents the dedicated intro overlay; Settings remains ordinary management UI underneath, and repeated activation while the intro is active is idempotent.
- [ ] On a completed installation, a manual redo runs all current steps and reaches workspace selection last; ordinary launch and the missing-agent upgrade path retain their existing behavior.
- [ ] There is only one onboarding-restart action in Settings, with no duplicate legacy row at the bottom.
- [ ] Showing or pressing the action does not itself clear permissions, authentication, workspace, provider, model, effort, or onboarding completion state.
- [ ] Focused regression tests and the full `swift test` suite pass.
