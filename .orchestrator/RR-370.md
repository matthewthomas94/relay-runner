## Description

Implement portable Markdown export plus explicit delete-audio and delete-session actions. Export title, stable session ID, date, manual notes, optional summary with model/provenance and timed transcript/speaker labels using clear sections. Only include audio by a separate explicit export choice if supported; ordinary Markdown export must not package it. Use atomic output with safe filenames, escaping and overwrite/error handling.

Apply the accepted retention default: proposed deletion of raw audio after successful final transcription, with explicit keep-audio; interrupted/untranscribed chunks remain recoverable. Audio-only deletion keeps text and explains lost replay/retranscription capability. Session deletion first invalidates jobs via the durable deletion marker, then removes app-owned DB content, all media/checkpoints/temp files, summaries and derived search entries. Reconcile failures on restart without resurrecting data; do not promise secure erasure from OS backups.

## Acceptance criteria

- [ ] Markdown fixtures round-trip readable content for multiline notes, Unicode, special characters, speaker names and timestamp links; source IDs and summary provenance survive export.
- [ ] Cancel/permission-denied/disk-full/overwrite failures leave a valid existing destination intact and report the real outcome without leaking content into logs.
- [ ] Retention never removes interrupted or still-required transcription audio; successful policy-driven expiry removes app-owned audio while preserving text and marking playback unavailable.
- [ ] Session deletion cancels/invalidate queued ASR and summary work, purges owned rows/files/indexes and remains deleted after late callbacks, retries and restart.
- [ ] Tests enumerate every app-owned media/checkpoint/cache path and verify no searchable remnants after completed deletion. Partial failures stay visible/retryable.
- [ ] The user-facing contract clearly distinguishes audio deletion, full session deletion and externally saved exports/backups.
