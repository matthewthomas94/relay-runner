## Description

Add an outer submenu to the session wheel's Settings segment. Two-thirds of that submenu arc is one continuous curved slider controlling the existing particle intensity setting; the remaining third is one Keep Awake on/off control. Match the existing detached liquid submenu, visual styling, haptics, hit testing, and motion. Clicking the main Settings wedge must still open Settings. Adjusting the slider or toggle must keep the wheel open.

The user supplied a Vorssaint screenshot with Keep Awake enabled indefinitely (infinity), "Active until you turn it off", and "Keep going with the lid closed" enabled. They want those behaviors combined into ONE toggle, without timers or extra visible keep-awake controls. They explicitly clarified: "Until I switch it off or quit Relay Runner". Thus this is app-lifetime keep awake, including idle periods between tasks, not the current task-activity-only assertion. The toggle should start off on a fresh launch, and quitting/update relaunch must end the mode. Keep the existing General setting and wheel control synchronized as the same feature with accurate labels/help. Do not silently activate this stronger behavior from an older saved task-only preference.

The current SleepPreventionController only holds a ProcessInfo idle-system-sleep assertion while a foreground task or worker is active. That does not implement the requested lid-closed behavior. Implement an authorized macOS system/lid-sleep path with a simple native authorization prompt when necessary, reliable restoration when turned off/quit, and recovery for interrupted transitions/crash. Keep mutations serialized; show pending/failure honestly and never claim success if authorization is canceled or sleep settings fail to change. Preserve a pre-existing system sleep-disabled state owned by another app instead of unconditionally resetting it. The implementation should remain appropriately small for this one feature; do not add timers, schedules, automation, battery preferences, or general-purpose settings frameworks.
