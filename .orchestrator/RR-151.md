### Annotated layout details

- Replace the centered `WorkspaceOverlayHeader` capsule with the compact leading menu-bar strip from node `843:1025`: x≈20, y≈7, height 24. It contains the Relay Runner mark followed by text tabs `Work`, `Terminal`, and `Settings`; tabs do not use the existing SF Symbol labels. The current tab is visually selected, while the other two retain clear hover/focus/click affordances and accessible labels. Preserve tab availability rules for project, workspace, and utility-only routes.
- The Relay Runner mark uses the same active/inactive asset decision as `MenuBarExtra` (`TrayIconActive` for an active session, `TrayIcon` otherwise). Feed session state into both the single-project and program-workspace chrome without introducing provider-specific behavior.
- The program overview column should match node `738:10545` (315.2×667 at the reference size, 24px horizontal and 16px vertical padding, 12px panel radius, fill `#090B0F`, border `#11161D`). Remove the old `Program Board` title/status/close block and the six metric tiles. The column retains only the Figma content hierarchy: `Workspace` plus the small state indicator and the session button in the first row; project count/scope and `Select all` in the next row; then the scrollable project cards.
- Move Start/End Session into the first row at the right. Match the Figma session-control sizing and visual vocabulary (approximately 130×32, capsule, icon plus sentence-case `Start session` / corresponding end-session copy). Preserve the existing action semantics and help/accessibility text.
- The project filter reads `Projects  <count>` with `All tickets` when no project is selected. `Select all` uses muted/disabled-looking text while all tickets are already selected, but remains a working, normally legible action when a project is selected.
- Project cards match node `839:668`: black fill, `#11161D` 1px border, 8px radius, 16px padding, 12px vertical rhythm. Show project name, middle-truncated path, then a two-column count grid ordered `Backlog`, `Queued`, `Done`, `In progress`. Remove provider chips and decorative shadow from the normal Figma presentation; keep selected, error, stale, and disabled states understandable without using color alone.
- Ticket cards match nodes `843:999` and `843:1011`: black fill, `#11161D` border, 8px radius, 16px padding, 12px vertical gap. The top metadata line is `RR-…` followed by the project name (ticket ID first), 14px regular muted text. The title is 16px semibold. Replace the icon-only editor with the 70×24 outlined capsule containing pencil plus `Edit`; retain disabled semantics when identity is unavailable.
- For active work, render the daemon-provided agent action/activity as the subdued final line shown at node `843:1023` (for example `Reviewing code`), including while the worker is active. Keep failure, dependency, review, and other non-redundant state information available, but avoid reintroducing duplicate lane/status prose. Truncate long activity text and expose the full value to hover and accessibility.
- Preserve drag/drop, create/edit/delete, project selection, Start/End Session, Terminal, Settings, escape dismissal, keyboard focus, and loading/error/empty behavior.

The implementation should also assess the single-project `BoardOverlayView`. Shared Workspace chrome and ticket-card vocabulary should remain coherent there, but do not add program-only project filtering or metrics to a single-project board.
