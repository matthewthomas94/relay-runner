## Description

Spec: `docs/specs/relay-remote.md` (Relay Remote: iOS voice over SSH), committed as `2a64cc0d` on branch `claude/ios-relay-ssh-tcp-spec-ddb8f2`. The spec is not on `main` yet; if the file is missing from your worktree, read it with `git show 2a64cc0d:docs/specs/relay-remote.md`. Read these sections first: Pairing and trust, Security model, Architecture.

Add the Mac-side pairing flow that makes a phone a trusted device, in the app's Settings, plus the code that manages `~/.ssh/authorized_keys` for it.

- Remote Login detection: probe `127.0.0.1:22` for the SSH banner; when absent, show a System Settings deep link to enable Remote Login and say that Relay Remote uses key authentication only.
- Pairing: generate an ephemeral Ed25519 pairing key; install it in `authorized_keys` as `command="<shim> --pair <pairing_id>",restrict,expiry-time="<now plus ten minutes>"`; start the `/tmp/relay_remote_pair.sock` listener; show a QR code containing the host candidates (LAN address, Bonjour name, Tailscale address when present), port, host key fingerprint, pairing id and the pairing private key. The QR payload is displayed once and never logged or persisted.
- The phone connects with the pairing key and sends its `device_id`, `device_name` and public device key. Show a confirmation sheet with the device name and the device key fingerprint. On accept, write the permanent line `command="<shim> --device <device_id>",restrict <key> relay-remote:<device_id>` and remove the pairing line. Offer an optional `from=` restriction to the Tailscale and LAN ranges.
- `authorized_keys` writer: atomic (temp file, fsync, rename); scoped to lines ending in the `relay-remote:<device_id>` marker; preserves every other line byte for byte; creates `~/.ssh` with mode 700 and the file with mode 600 when missing; refuses to write when either has group or world write bits and surfaces that instead of fixing permissions silently.
- Unpair removes exactly that device's lines.
- The shim at `~/Library/Application Support/relay-runner/bin/relay-remote-shell` is a tiny script rewritten at every app launch to exec the bundled helper from RR-425 inside the current app bundle, so `authorized_keys` never changes when the app moves.
- The Settings UI follows the RelayMotion conventions (blur plus fade, vertical rise and sink, swaps that never overlap).

Out of scope: the iOS side of pairing (RR-428), the user guide (RR-430).
