## Description

Add optional post-session generated notes from the selected transcript and manual notes. Support a user-configured local OpenAI-compatible endpoint and explicitly selected BYO OpenAI/Anthropic adapters. API model names are user-selected/validated at implementation time, not frozen to aliases in this ticket. Local-only users can leave generation disabled and retain a complete notebook.

Show destination, model and text categories before any hosted request. Never infer permission from Relay's Codex/Claude login or use its active CLI/messenger session. Store keys in Keychain. Use a tool-free summary pipeline: meeting text is data and cannot trigger tools, ticket creation, mail or web searches. Keep manual notes separate; summaries preserve source segment references, input revision/hash, provider/model/template version and editable revisions. Handle long inputs with bounded chunks and declared coverage.
