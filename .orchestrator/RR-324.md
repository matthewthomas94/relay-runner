## Description

Replace loosely coupled voice-turn state with a transactional lifecycle broker beside the durable intent inbox. Persist provider-turn identity, ownership, transitions, and effects atomically, then project that state into Swift. Bind this ticket to the accepted foreground-ownership containment ticket before promotion.

## Acceptance criteria

- [ ] Durable tables record provider turns, owners, lifecycle transitions, and user-visible effects with uniqueness constraints.
- [ ] State transitions are validated and atomically coupled to claim, acknowledgement, completion, recovery, and cancellation events.
- [ ] Every row is keyed by app session and recovery generation so stale owners cannot resume after restart.
- [ ] Swift consumes a deterministic projection of broker state rather than inferring ownership from independent event files.
- [ ] A documented dual-write migration and rollback path preserves compatibility during rollout.
- [ ] Codex and Claude fault tests prove that one accepted turn produces at most one authoritative effect.
