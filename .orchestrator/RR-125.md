## Description

Improve the live notch stream so it can show curated orchestration traces like the Codex transcript milestones the user pointed at: ticket creation, dispatch, run claim/running state, worker completion/failure, and board changes.

The goal is not to dump raw Codex/tool output into the notch. The notch should receive short, public, user-safe status updates that help the user feel the system is moving while work is being shaped or delegated. Keep raw shell commands, hidden reasoning, metadata dumps, and verbose transcript text out of the notch stream.

Use the existing PM-frontstage/status-event work where it helps. The likely integration points are the Relay bridge skill/script, `voice_state.sock` payloads, orchestrator run-status polling, and/or helper functions that let the foreground orchestrator mirror meaningful milestones into the notch consistently.

The feature should handle the real flow exercised in this session:

- a voice command asks for project work,
- the foreground orchestrator creates/refines a ticket,
- the ticket is dispatched to a worker,
- run state changes are checked,
- failures or completions are summarized.

## Acceptance criteria

- [ ] Add a small reusable path for emitting curated public trace updates to the notch via `/tmp/voice_state.sock`.
- [ ] The trace path supports at least ticket-created, dispatch-started/claimed, run-running, run-succeeded, run-failed, and board-change style messages.
- [ ] Relay/Codex foreground workflow guidance or helper code makes it easy to mirror meaningful orchestration milestones without copying raw shell commands.
- [ ] Public trace messages do not include raw command transcripts, hidden reasoning, shell snippets, or unbounded metadata.
- [ ] Codex and Claude provider parity is preserved or documented for any provider-specific differences.
- [ ] Add focused tests or deterministic harness coverage for trace payload shaping and stale-command behavior where applicable.
- [ ] Document how to manually exercise the trace stream in a voice session.
