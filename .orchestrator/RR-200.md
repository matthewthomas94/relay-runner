## Description

Extend the first-run onboarding completion phase with the four-screen interactive tutorial shown in the numbered design references below. The tutorial should teach the user Relay Runner's core voice and workspace controls by requiring the real gestures, rather than presenting a passive slideshow.

The existing setup prerequisites remain authoritative: permissions, agent choice, runtime preparation, authentication, and workspace selection must still complete before the tutorial exercises controls that require an active voice session. Start or attach the configured provider session through the existing shared session path, keep the onboarding surface active over that session, and do not mark onboarding complete until the final tutorial interaction succeeds.

The fourth tutorial screen replaces the current standalone `You’re all set /` completion prompt. Preserve the existing full-screen black onboarding visual language, reveal transitions, `Getting started` notch treatment, centered typography, blinking slash cursor, and keycap styling represented by the designs.

## Design references

Implement the sequence in numeric order:

1. `/Users/matthewthomas/Downloads/Session active - Onboarding tutorial 1.jpg`
2. `/Users/matthewthomas/Downloads/Session active - Onboarding tutorial 2.jpg`
3. `/Users/matthewthomas/Downloads/Session active - Onboarding tutorial 3.jpg`
4. `/Users/matthewthomas/Downloads/Session active - Onboarding tutorial 4.jpg`

The visible tutorial copy and illustrated keycaps should match these references:

1. Introduce learning the basics.
2. Teach Caps Lock recording: turn it on, say hello, and turn it off to send.
3. Teach Option playback/replay and Control cancellation.
4. Finish with the Shift workspace toggle and the final all-set message.

## Interaction sequence

1. Present the tutorial introduction after setup prerequisites and session startup are ready.
2. Advance the recording lesson only after the user starts recording with the real activation gesture, speaks, stops recording, and successfully sends the message.
3. Use the resulting response to exercise the real Option play/replay and Control cancel gestures. Advance only after the required gesture sequence is observed.
4. On the final screen, a real double-tap Shift must perform the normal Workspace toggle, complete onboarding, dismiss the tutorial surface, and leave the user in the usable Workspace.

## Acceptance criteria

- [ ] Fresh first-run onboarding transitions from the existing setup prerequisites into the four tutorial states in the numbered design order.
- [ ] Manual “Redo Onboarding” replays the same tutorial without corrupting an already configured workspace or creating duplicate sessions.
- [ ] A configured Codex or Claude voice session is active before the recording exercise begins, using the existing provider-neutral session launch and recovery paths.
- [ ] The tutorial uses real STT, message delivery, TTS playback/replay, cancellation, and Workspace gesture events; it cannot complete through timers or simulated gesture callbacks alone.
- [ ] The recording lesson advances only after a real start-recording → speech → stop-and-send cycle succeeds.
- [ ] The playback lesson responds to the real double-tap Option and double-tap Control gestures and advances only after the demonstrated sequence is completed.
- [ ] The final screen matches design 4, replaces the current standalone `You’re all set /` prompt, and completes only when double-tap Shift performs the normal Workspace toggle.
- [ ] On successful completion, onboarding flags are finalized once, the tutorial overlay is dismissed, and the Workspace remains usable.
- [ ] Quitting or relaunching during the tutorial resumes at a safe tutorial state without replaying completed setup work or marking onboarding complete early.
- [ ] Session startup or delivery failure produces a recoverable retry state instead of trapping the user in onboarding.
- [ ] Reduce Motion preserves the complete interactive sequence while removing nonessential motion.
- [ ] Tutorial copy, keycap labels, layout, transitions, and accessibility labels follow the four supplied visual references.
- [ ] Codex and Claude receive equivalent tutorial behavior and completion semantics.
- [ ] Automated tests cover tutorial state progression, real-event gating, resume/completion persistence, provider parity, failure recovery, and the removal of the old standalone completion prompt.
