## Description

Integrate only the baseline local engine selected by the feasibility result, behind the shared transcription seam. Start with stored synthetic/consented chunks so this can proceed alongside capture and UI. Implement visible model availability/download/verification/loading states, cancellation/retry, missing/unsupported locale and offline errors. Do not silently choose another model/provider or add cloud ASR.

Consume source-tagged audio on the canonical session timeline, persist processing cursors and reconcile partial/final segment revisions without duplicates. VAD and resampling must preserve real time rather than compress silence away. Raw recognized text, user corrections, source channel and optional speaker_id remain distinct. Manual local/remote/unknown speaker labels are baseline; automatic diarization is included only if the gate supports its quality/resources/terms, otherwise document it as deferred. [FluidAudio SDK](https://github.com/FluidInference/FluidAudio/blob/57551cd90e0bbec342766244358bcf08afb05290/README.md), [Apple result semantics](https://developer.apple.com/videos/play/wwdc2025/277/), [Anarlog model metadata](https://github.com/fastrepl/anarlog/blob/b9146a707f4da2121d3438bce38155b31e5007f1/crates/local-stt-core/src/lib.rs).
