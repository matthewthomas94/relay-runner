## Description

Upgrade the wheel opening and closing from the updated Figma keyframes: https://www.figma.com/design/IGjwpE5m7vLaCThHgoy0cw/Relay-Runner?node-id=1752-9156 . The latest user request replaces the circular sweep with simultaneous tile convergence and blur; the centre UI exits last.

On close, complete tiles (surface, icon and label) move inward together over 100 ms using the keyframe offsets: (0,30), (-20,20), (-22,-14), (0,-29), (20,-20), (20,20) points. Each tile retains its size through this convergence phase. Tile blur rises from zero to 48 points across the 200 ms exit; its requested final-300-ms window is capped to the shorter total duration so the resting tiles remain sharp. The black disc stays full size through this phase. The centre remains fully visible while its blur ramps from zero to 24 points across the 200 ms exit. During the final 100 ms the disc and blurred tiles contract to zero, the tiles fade, and the centre continues blurring and fades last. Tile blur and the centre stay clipped inside the disc. Opening reverses this 200 ms timeline: the disc and centre appear first, then tiles spread outward and sharpen together while the centre finishes sharpening over the 200 ms entry. Reuse the existing wheel geometry, assets, actions, paging, accessibility and provider-neutral session model.

Session/project menu and project-page changes animate one tile layer using the wheel's existing presentation renderer and reversible timeline. Preserve a value snapshot of the outgoing menu through its 200 ms contraction, swap content only when fully collapsed, then expand the new menu over 200 ms, for a 400 ms total menu change. The black disc and centre button remain fixed throughout; only the centre icon changes with navigation. Back during contraction reverses from the current frame, and canceled changes cannot swap stale content later. Reduce Motion uses short opacity fades. Outer action controls retain their wheel tile motion.
