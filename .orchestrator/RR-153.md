## Description

Extend the PP typography introduced for the Workspace in RR-152 into an app-wide Relay Runner typography system. The current code still uses semantic SwiftUI system fonts and direct `Font.system` or `NSFont.systemFont` declarations across Settings, onboarding, installer, permission guidance, Terminal chrome, status overlays, editors, and secondary Workspace UI.

Use the installed PostScript names already verified on this Mac:

- `PPMori-Regular`
- `PPMori-SemiBold`
- `PPTelegraf-Regular`

Generalize `WorkspaceTypography` into a shared app-level helper rather than creating parallel per-feature font utilities. PP Mori Semibold should carry app, screen, section, card, and control headings. PP Mori Regular may carry lower-emphasis titles where appropriate. PP Telegraf Regular should carry interface labels, body copy, captions, buttons, fields, actions, metadata, counts, provider/model text, and status copy.

Apply the shared roles to all text owned by Relay Runner, including:

- Workspace navigation, board content, editors, dialogs, empty states, dependencies, and run activity
- Settings window and all settings tabs
- Guided setup, parent onboarding, installer, and permission recovery guidance
- Notch, status, acknowledgement, and overlay labels, including AppKit text measurement/drawing paths
- Embedded Terminal chrome, status, controls, and empty/error copy
- Menu and app-owned control labels where SwiftUI/AppKit permits styling without replacing native behavior

Preserve functional typography exceptions:

- The terminal emulator grid remains monospaced.
- Code, shell commands, log excerpts, aligned identifiers, and intentionally monospaced paths remain monospaced.
- SF Symbols remain symbol glyphs; do not attempt to render them with the PP fonts.
- System-owned text inside native macOS controls may remain system-rendered where overriding it would break native behavior or accessibility. Document any intentional exception.

Keep the compact hierarchy established in RR-152. Do not translate Figma pixel sizes directly into oversized SwiftUI points, and do not cause layout growth, truncation regressions, or card/header inflation. Preserve existing colors, spacing, interaction, keyboard focus, accessibility labels, provider parity, and behavior.

Do not commit proprietary font binaries from `/Users/matthewthomas/Documents/Fonts/PP®F Starter Pack 5.2`. The app must continue to build and render with deterministic system-font fallbacks on machines and CI runners without the PP fonts installed.
