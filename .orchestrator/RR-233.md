## Description

Undo the product behavior introduced by RR-213: active Workspace ticket cards
must no longer render the animated blue-purple dot-matrix particle glow.

RR-213 was merged through `a8d13af`; its implementation commit is `aae4234`.
Reverse that feature against current `main` rather than blindly reverting the
historical commit, because `ProgramBoardOverlayView.swift` has received later
scrolling, dragging, and card-interaction fixes that must remain intact.

The RR-213 implementation added:

- `Sources/relay-runner/Board/ActiveTicketParticleGlow.swift`;
- the active-glow presentation and background hook in
  `ProgramBoardOverlayView.swift`;
- a shared `ParticleFieldAnimationClock` and associated renderer lifecycle
  changes in `ParticleFieldRenderer.swift`; and
- `ActiveTicketParticleGlowTests.swift`.

Remove the feature-only UI, support code, and tests. Restore the shared
`ParticleFieldRenderer` to the smallest correct post-rollback implementation
for its original STT/TTS overlay consumers. Preserve ticket activity state and
all nonvisual worker-status behavior; this rollback removes the RR-213
treatment, not the underlying indication that a worker is active.

Keep RR-213 and its run log as completed historical records. RR-233 is the
auditable reversal.
