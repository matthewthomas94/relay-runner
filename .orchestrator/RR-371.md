## Description

Add one bounded Workspace entry that opens the separate meeting app using deterministic OS application launch. If a selected opaque session UUID is supplied through an explicitly scoped user action, allow a deep link to focus that session inside the app. Validate scheme/host/UUID; do not include title, transcript, notes, audio, summary or provider credentials. A deep link cannot start recording or trigger generation.

When the app is absent, show a clear unavailable state. The entry works without an active bridge, project worker or agent session where Workspace itself is available. Closing Relay or ending Codex/Claude must not terminate the meeting app. Do not embed its UI/database or create a general localhost service. Source starting points: Sources/relay-runner/Board/WorkspaceOverlayShell.swift and the current registered-app launch patterns.

This ticket deliberately has no cross-repository depends_on ID: before dispatch, record the approved app-foundation counterpart as a Required input. Preserve that boundary when the app tickets leave this planning board.
