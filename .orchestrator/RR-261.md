## Description

Restore the notch status surface's one-sided expansion behavior.

When status text arrives and the notch surface expands, it currently grows from
both its left and right edges. That moves the status glyph even though the glyph
is the user's stable interaction target for opening the Workspace. From the
viewer's perspective, the glyph and right edge must remain fixed while the
surface reveals status text by extending only to the left. Hiding or shortening
the text must collapse along the same axis without shifting the glyph.

Trace both the placement calculation and the mounted `NSPanel` frame animation.
Do not rely only on drawing the glyph at an anchored local coordinate if the
panel frame itself still moves the glyph on screen. Preserve hover, click,
working animation, multi-display placement, fallback geometry, and accessibility
behavior. The notch UI is provider-neutral and must present the same status
geometry for Codex and Claude activity.

## Acceptance criteria

- [ ] A regression test demonstrates that current `main` moves the glyph's screen-space frame while transitioning between compact and expanded status content.
- [ ] On a notched display, compact-to-expanded, expanded-to-expanded, and expanded-to-compact transitions keep the glyph and right edge fixed in screen coordinates while only the left edge moves.
- [ ] The glyph's hover and click hit target remains aligned with the rendered glyph throughout and after an animated frame transition.
- [ ] Rapid status changes, text-width changes, working-state updates, and hide/show interruption do not accumulate drift or snap the glyph sideways.
- [ ] Multi-display selection and continuous-pill fallback behavior remain correct; any intentional fallback anchoring difference is documented and covered.
- [ ] Reduce Motion preserves the same final one-sided geometry without requiring animated interpolation.
- [ ] Focused notch placement, rendering, hover, click, and animation tests pass, including a mounted panel-frame test that asserts screen-space anchoring rather than only local drawing coordinates.
- [ ] A packaged-app smoke check confirms the notch reveals status text to the left without moving the interactive glyph, or records the precise display or permission blocker as an explicit post-merge human check.
