## Description

Verify the full Program Manager MVP across multiple projects.

Use at least two fixture or temporary repos with `.orchestrator/` boards. Exercise project registration/activation, Graphify Core ingestion, program status queries, Program Board rendering, native session review capture, and the Graphify code-indexing MVP slice.

This ticket should produce a clear verification report and fix small integration gaps only if they are directly required for the MVP to pass.

Provider parity matters: the verification should include provider metadata or simulated provider differences for Codex and Claude where feasible.

## Acceptance criteria

- [ ] At least two projects are registered and visible to the Program Manager.
- [ ] Each project has distinct `.orchestrator` tickets ingested into Graphify Core.
- [ ] Program status queries report active, blocked, and awaiting-merge style states across projects.
- [ ] The Program Board opens and displays cross-project data without breaking the existing project board.
- [ ] Native session review capture writes events and links them to project/ticket/run nodes.
- [ ] The Graphify code-indexing MVP slice is exercised on at least one repo.
- [ ] Provider-neutral behavior is verified for Codex and Claude metadata or documented test doubles.
- [ ] A verification report is added to the repo, including commands run, results, and any residual risks.
