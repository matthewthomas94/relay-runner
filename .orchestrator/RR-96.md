## Description

The board hotkey should change from the current Control/Option/Command-style chord to a double-tap Shift gesture. The goal is a faster, easier gesture for bringing up the Relay Runner board without requiring the user to remember a multi-modifier shortcut.

Keep this focused on the board toggle gesture. Existing menu-bar board controls, RelayActions `toggle_board`, and any non-keyboard board entry points should continue to work. Be careful not to interfere with existing double-tap Option/Control behavior used for voice playback/cancel controls, normal Shift usage while typing, or accessibility expectations around modifier keys.

Provider parity matters. Codex and Claude sessions should get the same board-toggle behavior because the gesture belongs to Relay Runner, not a provider-specific agent path.

## Acceptance criteria

- [x] Double-tapping Shift toggles the Relay Runner board using the same board-opening path as the existing hotkey.
- [x] The old Control/Option/Command board hotkey is removed or disabled from the active global listener, unless there is a deliberate documented compatibility reason to keep it.
- [x] Double-tap Shift detection has a clear timing threshold and does not fire from ordinary single Shift presses.
- [x] The gesture does not interfere with existing double-tap Option/Control voice playback or cancel controls.
- [x] The menu-bar board action and RelayActions `toggle_board` behavior continue to work unchanged.
- [x] Input Monitoring or onboarding/status copy that names the board hotkey is updated from the old chord to double-tap Shift.
- [x] Add focused Swift tests for the Shift double-tap detector and for preserving non-keyboard board toggle paths.
