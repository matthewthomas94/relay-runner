## Description

Wire capture, ASR, storage and workspace into one session coordinator. Start must bind the selected sources/model/retention choices to a stable session; stop capture before draining ASR and committing complete state. Record-for-later is an explicit mode if accepted by the gate. Cancel generation, stop recording and delete a session remain distinct scoped actions.

On launch find interrupted sessions, reconcile finalized chunks/manifests and processing cursors, preserve manual edits, and offer recovery or discard without overwriting a good session. Reprocessing only replaces the audio range it actually heard; a truncated batch cannot erase later transcript text. Handle close/quit, source loss, low disk, model failure and repeated Stop. Prefer resumable disk chunks over a whole-meeting RAM buffer. [Logue recovery reference](https://github.com/bitwize-ai/Logue/blob/ea61172f33970d40b9f9b5e4c52f30eb82836e58/Logue/Services/RecordingSessionManager+Recovery.swift), [Meetily checkpoints](https://github.com/Zackriya-Solutions/meetily/blob/a2cb62e827da7ef59f65064c97233efb2313878e/frontend/src-tauri/src/audio/incremental_saver.rs).
