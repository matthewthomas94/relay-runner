## Description

Use the established Settings action-button treatment for these Workspace controls:

- `Select all` in the Projects board header
- Edit actions shown on individual ticket cards
- Edit actions in ticket detail surfaces

Match the buttons used for Redo Onboarding, Browse, Revert, and Save: compact rounded rectangles rather than the fully rounded capsule treatment currently used in Workspace. Reuse a shared component or style so Settings and Workspace cannot drift into visually similar but different implementations.

Limit this change to actionable controls. Status labels, counts, and badges may retain their existing pill shapes.

## Acceptance criteria

- [ ] Projects `Select all` uses the same 28-point control height, 6-point continuous corner radius, typography, spacing, border, and fill treatment as Settings action buttons.
- [ ] Ticket-card and ticket-detail Edit actions use the same Settings action-button geometry and icon/text treatment.
- [ ] The targeted Workspace controls no longer render with fully rounded capsule backgrounds.
- [ ] Settings and Workspace consume one shared action-button component or presentation style rather than duplicating the visual constants.
- [ ] Hover, keyboard focus, pressed, disabled, and Reduce Motion behavior matches the corresponding Settings button states.
- [ ] Workspace colors adapt the shared treatment to the existing dark surface without changing its geometry or interaction language.
- [ ] `Select all` still communicates whether the all-projects scope is active.
- [ ] Edit actions retain their existing enablement rules, help text, accessibility labels, click behavior, and ticket identity checks.
- [ ] Status badges, state pills, counts, and other non-action indicators are unchanged.
- [ ] Automated tests cover the shared style contract, Projects selection state, enabled and disabled Edit controls, keyboard focus, and accessibility labels.
- [ ] Visual verification compares the targeted Workspace controls with Redo Onboarding, Browse, Revert, and Save at supported window sizes.
