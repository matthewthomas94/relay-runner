## Description

The user wants every UI transition in the Relay Remote iPhone app (`ios/RelayRemote`) to feel as smooth and liquid as the Agents dock does when it rises out of the tab bar and melts back into it (RR-552, `MainTabView.glassLayer`, one `GlassEffectContainer` with `glassEffectID`s). Today several transitions step, overlap or jump instead of moving as one continuous motion.

Go through every transition in the app and make each one smooth, keeping the standing Relay Remote rules:
- Motion follows the Mac app's motion styles and the shared `RelayMotion` kit (`ios/RelayRemote/DesignSystem/RelayMotion.swift`): blur, fade and a 96% scale, and swaps that never overlap (old content leaves before new arrives). Use the Emil Kowalski animation skills (`animate`, `review-animations`, `choreograph`).
- Frequent actions stay snappy (tab switches, sending, Play, Stop, agent tab switches about 200 to 300 ms). Haptics stay on taps.
- Reduce Motion keeps only fades.
- Glass follows the Figma "Relay Remote (iOS) · Final" section (file `IGjwpE5m7vLaCThHgoy0cw`, node `2139:37371`), including the design changes below.

Surfaces to audit at least: tab switches (pages and the tab bar pill); the dock and its controls (talk button faces, Replay/Cancel swap, the text box growing with the transcript, the keyboard rising and the tab bar stepping aside); agent tab switching and the chat crossfade; chat rows arriving, the "New reply" card turning into the reply on Play; the state glows (listening and playback rising and sinking, `AppGlowLayer`); onboarding stage swaps, permission steps, pairing steps and tutorial steps; the ticket modal opening and closing (`TicketModalView`); banners; Workspace list changes and the project tab pill; Settings segmented controls, switches and the speed slider.

**New designs to build (user, 2026-11-27, Figma Final section)**. Build these, then animate them as below:
- **Clearer glass everywhere:** every surface is more transparent so more of the backdrop shows through. Fill opacities in Figma: glass panels (Settings panel, message dock) neutral-2 `#0c0f13` 50% → 30%; tab bar 70% → 45%; controls and secondary buttons neutral-3 `#171a1e` 75% → 50%; selected pills neutral-4 `#212529` 75% → 50%; solid neutral-3 cards and pills (Workspace ticket cards, selected project tab) → 60%; black text boxes → 50%; other neutral-4 fills → 65%. Dividers, white buttons and red labels unchanged.
- **One message panel on Agents (21–25):** the agent tab strip moves inside the dock as its top row, so agent tabs, the text box and Replay/Stop are one glass panel (10 pt padding, 8 pt gaps, radius 20). The strip still scrolls sideways inside it; the selected agent keeps its outlined pill. On Mac unreachable (25) the panel dims as a whole, the tabs inside are not dimmed twice.
- **Workspace project tabs in their own glass container (26):** the tab bar's glass, 4 pt padding, radius 20, 12 pt above the tab bar.
- **Speech speed slider (Settings 27) copies the Mac's `SettingsSlider`** (`Sources/relay-runner/Settings/SettingsInputControls.swift`): a 44 pt rounded track (radius 12, neutral-3), a white 72% value fill up to a 2.5 pt upright thumb (8 pt inset from the ends, soft shadow), and the value as a 12 pt caption inside the track, neutral-7 to the right of the thumb, dark on the fill once past halfway. Full row width under the "Speech speed" label.
- **Listening state on Workspace and Settings (26b, 27b):** the orange listening dot field rises behind the UI on every tab, not only Agents; the project tabs container, the message panel and the tab bar sit in front of it, and it shows through the faded scroll edge.

**Tab transitions between the glass containers (user, 2026-11-27; replaces RR-552's "dock always melts into the tab bar")**. The tab bar stays put; only the glass above it changes shape, as liquid glass in one `GlassEffectContainer`, contents fading so only the glass morphs:
- Agents → Workspace: the message dock (agent tabs, text box, Replay/Stop, now one glass panel) reshapes straight into the Workspace project tabs container; it does not go through the tab bar. Workspace → Agents reverses it.
- Agents → Settings: the message dock melts down into the tab bar; Settings → Agents, it rises back out.
- Workspace → Settings: the project tabs container melts down into the tab bar; Settings → Workspace, it rises back out.
Figma reference: the note "Dock (Agents, 21–25)" (node `2159:10342`) in the Final section.

Known pitfalls from recent work: an implicit `.animation` that chases a value which already moves with a page transition makes it lurch (the dock did this until commit 1fe00644); fading a multi-layer view without `.compositingGroup()` flashes (the backdrop did this); a glass background view inside a `GlassEffectContainer` can draw over text.

## Acceptance criteria

- A short audit list in the ticket's run log: each transition, what was wrong (or "already smooth"), and what changed.
- Every changed transition uses `RelayMotion` curves or a documented spring, with no multi-stage jumps, overlapping states or flashes, verified frame by frame from simulator recordings (`xcrun simctl io <sim> recordVideo`, the debug launch arguments in `ios/README.md`, such as `--cycle-tabs`, `--agents-sample=play-demo`, `--tutorial-step`, `--ticket-sample`).
- Frequent actions stay within about 300 ms; Reduce Motion is honoured.
- Existing iOS tests pass (`xcodebuild test` on the RelayRemote scheme) and a Release build for a device succeeds.
