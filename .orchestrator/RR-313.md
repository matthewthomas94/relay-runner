## Description

Make the onboarding copy choreography consistent with the cursor-led deletion and retyping established at the beginning of the cinematic. A user recording of the signed v0.4.43 flow shows that later non-tutorial steps replace whole surfaces or titles with opacity fades, so the blinking cursor disappears with one phrase and reappears with the next instead of carrying the transition.

Outside the session-controls tutorial, keep one continuous title/cursor presentation and transition between prompts by backspacing the current graphemes, then typing the next prompt with the existing `OnboardingPromptTransitionTimeline` behavior. This applies across permission, provider choice, runtime preparation/readiness/failure, provider login, and any project/workspace setup prompt that remains part of onboarding. Controls may appear after their target title is established, but a non-tutorial title or whole onboarding surface must not be replaced by an opacity crossfade. Fade-out/fade-in prompt changes remain intentional only inside the tutorial sequence.

Also repair the opening handoff from the **Relay Runner** title card to **First thing’s first**. It currently collapses too quickly after the title card completes. The title must receive an intentional settle, then leave with the same legible per-grapheme cadence and spatial continuity with which it arrived before the next phrase begins. Reuse and unify the existing timeline primitives rather than adding a second animation system or changing onboarding copy, button behavior, setup sequencing, or provider routing.

Follow the existing accessibility contract: Reduce Motion must use a deterministic static or gentler non-spatial alternative and must not replay the full cursor animation solely to satisfy visual parity.

## Acceptance criteria

- [ ] The implementation inventories every title-bearing onboarding phase and encodes an explicit transition policy: all non-tutorial phase changes are cursor-led erase-then-type transitions, while opacity prompt transitions are limited to `OnboardingSessionControlsTutorial` presentation.
- [ ] Moving between permission, provider choice, runtime, login, project/workspace, success, retry, and error states preserves one coherent title/cursor handoff; the old copy visibly backspaces before the new copy types, with no frame where an unrelated old and new title crossfade through each other.
- [ ] Non-tutorial view replacement no longer fades the complete onboarding surface merely to change prompts. Controls and status content may reveal at the appropriate phase without making the title cursor disappear and reappear abruptly.
- [ ] The **Relay Runner** title remains fully readable for an intentional settle after its entrance and exits with a legible per-grapheme cadence that mirrors the entrance before **First thing’s first** starts; there is no abrupt bulk deletion, cut, or immediate next-phrase flash.
- [ ] The opening title handoff uses the same shared timing policy as later non-tutorial cursor transitions where appropriate, avoiding duplicated magic durations and preserving Unicode grapheme correctness.
- [ ] Tutorial recording, playback, cancellation, and Workspace instructions retain their deliberate fade-out/fade-in treatment and existing interaction gates.
- [ ] Reduce Motion bypasses or simplifies cursor animation deterministically without introducing large movement, trapping setup, hiding actionable state, or changing the final prompt and controls.
- [ ] Codex and Claude setup paths produce equivalent transition behavior, including provider-specific preparation, ready, login, retry, and failure copy.
- [ ] Focused tests cover the title-card settle and symmetric exit cadence, phase-to-policy mapping, cursor continuity across representative non-tutorial boundaries, tutorial-only fade policy, Unicode graphemes, interruption/re-entry, and Reduce Motion.
- [ ] Relevant Swift tests pass, and a fresh mounted onboarding recording confirms the title-card handoff is calm and legible, all later non-tutorial copy changes backspace/retype, and only the tutorial portion crossfades.
