## Description

Remove filesystem metadata reads and identity reconstruction from the Program
Workspace lane comparator. Carry one stable modification/sort key per dashboard
item or precompute ordered lane arrays when a snapshot changes, then render
those stable values without restatting files.

RR-237 measured 553/708 ms p50/p95 lane sorting with 227 tickets, delaying an
eligible drag by 761 ms and hover feedback by 792 ms. The remediation must move
that work outside SwiftUI body evaluation while preserving deterministic
ordering in both Project and Program scopes.
