## Description

Correct the RR-157 implementation so Terminal and Settings explicitly expand to the width offered by the Workspace shells. RR-157 replaced the old finite caps with `WorkspaceSurfaceSizing.terminalMaxWidth` and `settingsMaxWidth` values of `nil`. In SwiftUI, `maxWidth: nil` removes the flexible maximum instead of opting into fill-width behavior; a local `NSHostingView` probe given a 1000-point width measured a 36-point child with `nil` and a 1000-point child with `.infinity`.

Use `.infinity` semantics for both workspace surfaces, matching the Work panels' existing `.frame(maxWidth: .infinity, ...)` contract. Keep the change surgical. Preserve the fixed vertical geometry, shared shell gutters, standalone Settings window size, and all Terminal/Settings behavior. Update the RR-157 regression coverage so it fails for `nil` and finite caps and passes only for explicit fill-width sizing.
