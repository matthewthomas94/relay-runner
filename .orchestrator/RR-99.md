## Description

Research and record the exact Codex support contract for GPT-5.6 before implementing app-facing controls.

Current findings to verify:

- OpenAI's GPT-5.6 preview announcement describes GPT-5.6 Sol as the flagship reasoning model, Terra as a balanced model, Luna as the fastest/cost-efficient model, plus new `max` reasoning effort and Ultra mode.
- OpenAI Help lists the preview model IDs as `gpt-5.6-sol`, `gpt-5.6-terra`, and `gpt-5.6-luna`; API and Codex access is limited to trusted partners during preview and there is no public GA date yet.
- Current Relay Runner Codex model choices include `default`, `gpt-5.5`, `gpt-5.4`, `gpt-5.4-mini`, and `gpt-5.3-codex-spark`, but not GPT-5.6 preview models.
- Current Codex docs still document `model_reasoning_effort` as `minimal`, `low`, `medium`, `high`, and `xhigh`; the public docs need to be checked for when or how `max` becomes a Codex CLI/app config value.

Primary sources:

- https://openai.com/index/previewing-gpt-5-6-sol/
- https://help.openai.com/en/articles/12356340-gpt-5-6-in-chatgpt-and-the-api
- https://developers.openai.com/codex/codex-manual.md
