## Description

Relay Runner currently lets users choose the agent provider and model, but it does not expose Codex reasoning effort. GPT-5.6 preview introduces a new `max` reasoning level, and existing Codex docs already expose `model_reasoning_effort` for supported models.

Add a Codex-scoped reasoning effort setting once RR-99 confirms the current CLI/app contract. Keep the implementation narrow: this should configure Codex launch behavior and app persistence only, not redesign provider selection.

If `max` is not accepted by the installed/current Codex surface yet, support the documented stable effort set and leave `max` hidden or disabled with a clear preview note in the verification/run log.
