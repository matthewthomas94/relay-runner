## Description

Harden messenger and sidecar process launches so only the foreground orchestrator can own an authoritative reply, completion hook, or app-session voice identity. Add an explicit actor-role contract and gate Swift playback against the current app session, recovery generation, foreground role, and gate handle. This is the urgent containment prerequisite for the durable lifecycle work.

## Acceptance criteria

- [ ] Messenger and sidecar child environments remove foreground reply ownership, completion-hook ownership, turn identity, and gate-handle variables.
- [ ] Every voice-producing process carries an explicit actor role and only the foreground role can request an authoritative reply.
- [ ] Swift rejects playback whose app session, recovery generation, actor role, or gate handle does not match the current foreground owner.
- [ ] Codex and Claude integration tests cover child-process isolation, stale recovery generations, and competing reply attempts.
- [ ] Diagnostics expose only allowlisted identity metadata needed to correlate ownership decisions.
