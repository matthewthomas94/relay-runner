## Description

Stop the onboarding prompt from nudging horizontally when its trailing slash blinks. The cursor must remain present in the laid-out string at all times and alternate only between 50% and 100% opacity. Apply the same stable-width treatment to both the AppKit cinematic/permission prompt renderer and the SwiftUI provider, runtime, login, and workspace titles.

Implement this inline as a focused follow-up to RR-191; do not dispatch a worker.

## Acceptance criteria

- [ ] The trailing slash remains in the rendered string throughout every blink phase.
- [ ] The slash alternates between 50% and 100% opacity without changing text metrics.
- [ ] Cinematic typing/backspacing and permission prompts remain center-aligned without horizontal nudging.
- [ ] Hosted provider, runtime, login, and workspace titles use the same stable-width blink treatment.
- [ ] Focused onboarding regressions and the full Swift test suite pass.
- [ ] A new DMG and installed app bundle are verified before launch.
