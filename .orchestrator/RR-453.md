## Description

Product rule from the user: a checkbox is only for multi-select lists. Every on/off setting must be a toggle switch. Today every boolean in Settings renders through `SettingsCheckboxStyle` (`Sources/relay-runner/Settings/SettingsInputControls.swift`), applied by `SettingsStack` and `SettingsControlRow` in `Sources/relay-runner/Settings/SettingsComponents.swift`, and there are no multi-select checkbox lists in the app.

Work:

1. Replace the checkbox rendering with a switch: a pill track with a sliding knob, sized for the settings rows, using the existing `SettingsSurfaceColor` tokens for track/knob in both on and off states and the app's accent for the on state. Keep the type name or rename to `SettingsSwitchStyle` and update the two application sites; either way, every existing `Toggle` in Settings picks it up without per-call-site edits.
2. Animate the knob with the RelayMotion kit's standard easing (no spring overshoot, no overlapping swaps), and keep the control usable without animation under Reduce Motion.
3. Accessibility: the representation becomes a switch (`.toggleStyle(.switch)` equivalent), with the same label and value semantics as before.
4. Audit the call sites and confirm they are all single booleans: Awareness (screen_glow, live_transcription, live_captions), Text-to-Speech (show_notification), General (wheel_haptics, auto_start, bypass_permissions, Keep Awake), Relay Remote (restrictToNetwork) and the Custom Voices consent affirmation. All of them switch. Do not change the Onboarding radio rows; they are single-select, not checkboxes.
5. Update the settings UI tests that assert on the checkbox representation, if any.

## Acceptance criteria

- [ ] No `SettingsCheckbox` square rendering remains; every boolean `Toggle` in Settings renders as a switch through the shared style, verified by a test that instantiates the style and checks its accessibility representation is a switch.
- [ ] On/off colours come from `SettingsSurfaceColor` and the accent token; nothing is hard-coded.
- [ ] Knob movement uses the RelayMotion easing and honours Reduce Motion.
- [ ] `swift build` and `RelayRunnerTests` pass; Relay Vision screenshots of the Awareness and General pages (on and off states) are attached to the run log if a build can be launched, otherwise say so.
