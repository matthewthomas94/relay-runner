## Description

Make the Program Manager distinguish a workspace root from a project repo as a first-class model.

The selected workspace folder is the user-level folder where Relay Runner starts sessions and discovers projects. It should not become a Program Manager project or get a parent `.orchestrator/` just because it contains repos. A child git repo remains a project and owns its own `.orchestrator/` board.

Implement the central registry/config shape needed to persist workspace roots and the discovery classifier:

- non-git folder with child git repos means workspace root
- git repo without child git repos means single project
- git repo with child git repos means workspace root by default, with the parent repo only registered if the user explicitly activates it as a project
- non-git folder without child repos is refused or asks the user to initialize/select a different folder

Provider parity matters. The stored workspace/project model should be provider-neutral so Codex and Claude sessions resolve the same workspace and project set unless a provider-specific limitation is intentionally documented.

## Acceptance criteria

- [x] A central Relay Runner data model can persist one or more workspace roots separately from registered project repos.
- [x] Project registration from discovery registers child git repos without registering the workspace root as a project by default.
- [x] Existing explicit project activation still registers a single repo as a project and initializes its local `.orchestrator/config.toml` when appropriate.
- [x] Non-git folders with no child repos do not silently run `git init` and surface a clear refusal or next step.
- [x] Git repos that contain child repos are treated as workspace roots by default without creating a parent `.orchestrator/`.
- [x] Codex and Claude use the same workspace/project registry semantics, with any intentional differences documented.
- [x] Unit tests cover non-git workspace with children, single git repo, git repo with children, and non-git folder with no projects.
