## Description

The Workspace terminal panel renders one terminal: `WorkspaceTerminalPanel` (`Sources/relay-runner/Terminal/EmbeddedTerminal.swift` ~3863) always shows `EmbeddedTerminalTab(session: appState.embeddedTerminal)`, and `EmbeddedTerminalHostNSView` (~3628) borrows that session's single `hostedView`.

After RR-394 there can be several sessions. Show one tab per running session in the terminal panel, labelled with the project name. Selecting a tab focuses that project (sets the focused context, which routes voice there). Closing a tab stops that project's session (same path as Stop). The focused session's tab is selected whenever focus changes from elsewhere (project card, MCP). Follow the RelayMotion conventions for any tab transitions.

## Acceptance criteria

- [ ] Two running sessions show two tabs labelled with their project names.
- [ ] Selecting a tab sets the focused context and shows that session's live terminal, with its scrollback intact.
- [ ] Closing a tab stops only that project's session; the other tab and process remain.
- [ ] Focusing a project elsewhere selects its tab.
- [ ] With one session the panel still works with a single tab.
