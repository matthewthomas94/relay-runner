## Description

Update the project guidance, user docs, generated skills, and workflow prompts so they describe the persistent orchestrator architecture instead of the current foreground-session-as-orchestrator model.

Audit findings:

- `AGENTS.md` currently says the user thinks of this session as the orchestrator and that the foreground session writes/refines tickets and integrates workers.
- `docs/orchestrator.md` describes the main Codex/Claude session as the orchestrator and the worker as the sub-agent.
- `services/command_actions.py` formats project-work commands with a "foreground orchestrator" contract.
- `services/orchestrator_workflow.md` describes one-shot workers dispatched by the orchestrator and restricts workers to one ticket.
- `scripts/relay-bridge` generates installed Claude/Codex Relay skills whose instructions carry the old PM/orchestrator responsibilities.
- Relay-specific skills under `~/.codex/skills/relay-*` and `~/.claude/commands/relay-*` are generated from the repo and should be regenerated/verified after source updates.

## Acceptance criteria

- [ ] `AGENTS.md` describes PM frontstage, persistent orchestrator tech lead, worker executors, and provider parity.
- [ ] `docs/orchestrator.md` documents the full RR-Loop sequence: parallel raw instruction fanout, PM acknowledgement/status, orchestrator ticket authoring, PM worker creation, worker execution, orchestrator review/merge, and PM status updates.
- [ ] `services/orchestrator_workflow.md` remains accurate for worker agents under the new model.
- [ ] Generated Relay bridge/workflow/dispatch skills in `scripts/relay-bridge` are updated so Codex and Claude get equivalent instructions.
- [ ] Any installed local skill files that should be regenerated are documented or refreshed through the supported install path.
- [ ] Docs preserve the privacy rule: raw Relay command captures are private metadata, not visible ticket prose.
- [ ] Add or update tests that assert generated instruction text no longer says the foreground session writes/refines tickets as the orchestrator.
