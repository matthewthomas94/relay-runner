## Description

Ingest registered projects into Graphify Core.

The ingestion pass should scan each registered repo's `.orchestrator/` directory and the orchestrator run history, then upsert graph nodes/edges for projects, tickets, dependencies, runs, providers, and merge/run states.

Keep this ticket read-only with respect to project ticket files. It should build the program index from repo-local sources of truth, not move source-of-truth state into the program layer.

Provider parity matters: both Codex and Claude runs should be represented consistently in the ingested graph, even if the underlying provider-specific metadata differs.

## Acceptance criteria

- [ ] The ingester iterates all registered projects from RR-38.
- [ ] Tickets from each repo's `.orchestrator/*.md` are represented as graph nodes linked to their project.
- [ ] Ticket dependencies are represented as graph edges.
- [ ] Orchestrator run history is represented as Run nodes linked to tickets/projects.
- [ ] Active, succeeded, failed, stalled, and awaiting-merge style states are preserved or mapped clearly.
- [ ] Ingestion is idempotent: re-running it does not duplicate nodes or edges.
- [ ] The ingester does not modify ticket files or project working trees.
- [ ] Tests cover at least two fixture repos with distinct ticket prefixes and dependencies.
