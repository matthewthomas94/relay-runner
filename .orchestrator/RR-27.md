## Description

Relay Runner's current DMG flow is the conventional "drag app to Applications" pattern. The Codex macOS installer flow observed by the user is a stronger product reference:

- User mounts a DMG.
- A custom installer window opens instead of a drag-to-Applications window.
- The window says "Install Codex" and asks the user to double-click the app icon.
- macOS Gatekeeper shows the normal downloaded-app "Open" prompt.
- The installer shows in-window copy/install progress while moving the app to `/Applications`.
- The app launches automatically after install.

Ignore the observed unrelated helper-tool prompt from another app; that is not part of the Codex installer reference. Also avoid copying the observed typo from Codex's progress copy.

Design and implement the equivalent Relay Runner install experience, using Relay Runner branding and preserving the existing build/signing/notarization path where applicable.

## Acceptance criteria

- [ ] The release DMG opens a custom Relay Runner installer window rather than relying only on "drag to Applications" instructions.
- [ ] The installer gives one clear action to install, such as double-clicking the Relay Runner app icon.
- [ ] The app is copied into `/Applications` with visible progress and a clear success state.
- [ ] Relay Runner launches automatically after a successful install.
- [ ] Gatekeeper behavior remains normal for a downloaded macOS app; do not try to bypass macOS security prompts.
- [ ] Existing DMG build outputs remain scriptable through the project build pipeline.
- [ ] Installer copy and progress text use Relay Runner naming and do not include the Codex "Codes" typo.
- [ ] Verification covers a clean local DMG install path and confirms `/Applications/Relay Runner.app` is refreshed.
