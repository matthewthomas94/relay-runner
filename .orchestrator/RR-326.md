## Description

Create a bounded compatibility probe for the three Relay MCP adapters. Compare the current legacy surface with the 2026-07-28 stateless lifecycle surface using fixtures and installed-client handshakes, then make an evidence-backed stay, dual-speak, or migrate decision. Keep voice delivery outside the MCP transport boundary.

## Acceptance criteria

- [ ] Fixtures exercise initialize negotiation, stateless request handling, request handles, cancellation, and error behavior for all three Relay MCP adapters.
- [ ] Installed supported clients are probed and their negotiated capabilities are recorded with reproducible commands and expected results.
- [ ] The report distinguishes protocol support from the separate Relay voice-delivery channel.
- [ ] The report recommends staying legacy, dual-speaking, or migrating and identifies compatibility risks and rollback conditions.
- [ ] No production adapter behavior changes as part of this probe.
