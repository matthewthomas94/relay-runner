## Description

Build the MVP Graphify Core data layer for Program Manager mode.

Graphify Core is not deep code intelligence yet. It is the native program graph foundation: projects, initiatives, tickets, runs, agents, risks, decisions, and relationships between them. The store should support simple graph queries that later status/UI tickets can consume.

Use RR-36 for product scope and RR-37 for backend recommendations. Keep this ticket focused on the store schema, write/read/query APIs, and tests.

Provider parity matters: graph nodes and edges for agent/provider/run state must represent Codex and Claude without assuming either one is the only provider.

## Acceptance criteria

- [ ] A Graphify Core store/schema exists for nodes and edges or equivalent graph-shaped records.
- [ ] The store can represent at least Project, Initiative, Ticket, Run, AgentProvider, Risk, and Decision nodes.
- [ ] The store can represent at least belongs_to, contains, depends_on, blocks, executes, awaits_merge, related_to, and uses_provider relationships.
- [ ] Public APIs exist to upsert nodes/edges and query relationships needed by later tickets.
- [ ] The graph data model records enough provider/run metadata for both Codex and Claude runs.
- [ ] The implementation avoids deep code indexing in this ticket except for placeholders or documented future extension points.
- [ ] Unit tests cover basic upsert, idempotent re-upsert, relationship query, and provider-neutral run representation.
- [ ] Existing orchestrator tests continue to pass, or any skipped tests are explained.
