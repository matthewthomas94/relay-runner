## Description

Background: RR-448 (done) scoped porting the Python services in `services/` to Rust. Read its `## Spike report` first; it holds the inventory, interface list, evidence and staged plan. Use `scripts/relay-ticket-history show RR-448` if the ticket has been archived.

Nothing in this repo builds Rust today. `cargo` and `rustc` are not installed on the developer Mac and `.github/workflows/build-dmg.yml` (runner `macos-15`) installs no Rust toolchain. The bundle already ships one prebuilt Rust binary, `agent-desktop`, signed in the helper loop of `scripts/build-dmg.sh` (about lines 369-446) with `codesign --force --timestamp --options runtime` and no entitlements. That is the precedent to follow.

Add the foundation every later Rust ticket builds on:

- A Cargo workspace at `rust/` in the repo root with a committed `Cargo.lock` and a `rust-toolchain.toml` that pins a stable toolchain.
- One binary crate, `relay-rs`, whose only behaviour is `relay-rs --version`, printing the `CFBundleShortVersionString` and `CFBundleVersion` it was built with. Later tickets add real subcommands or sibling crates.
- `scripts/build-dmg.sh` builds the workspace in release mode for `aarch64-apple-darwin`, copies the binary to `Contents/MacOS/`, and signs it in the same loop as the other helpers. A missing Rust toolchain must fail the build with a clear message that names the install command, before anything is replaced in `/Applications`.
- CI installs the pinned toolchain, caches cargo, and runs `cargo fmt --check`, `cargo clippy -- -D warnings` and `cargo test` for the workspace.
- `services/app_signing.py check-helper` (or the equivalent existing check) covers the new binary.
- `THIRD_PARTY_NOTICES.md` gains a section generated from the Rust dependency tree (for example with `cargo-about` or `cargo-deny`), and CI fails on a licence outside an explicit allow list. GPL and AGPL must not be on that list.
- `TESTING.md` and `docs/release-updates.md` say how to install Rust locally and how Rust is built into a release.

Do not port any Python behaviour in this ticket.

## Acceptance criteria

- [ ] `rust/` holds a Cargo workspace with a pinned toolchain and committed lockfile, and `cargo test`, `cargo fmt --check` and `cargo clippy -- -D warnings` pass.
- [ ] `./scripts/build-dmg.sh` produces an app whose `Contents/MacOS/relay-rs --version` prints the bundle's version and build, and `codesign --verify --deep --strict` passes on the bundle.
- [ ] With no Rust toolchain on PATH, the build stops before replacing the installed app and names the fix.
- [ ] CI builds and tests the workspace, and the tag release build still publishes `RelayRunner.dmg`, `RelayRunner.zip` and `appcast.xml`.
- [ ] A licence check runs in CI, rejects GPL-family licences, and `THIRD_PARTY_NOTICES.md` lists the Rust dependencies.
- [ ] The run log records the size the Rust binary adds to the bundle.
