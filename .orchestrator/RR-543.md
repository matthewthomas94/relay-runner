## Description

Build the Workspace tab, screen 26 (`docs/design/relay-remote-ios/README.md`, section "Workspace tab"; image `26-workspace.jpg`; Figma [2139:49283](https://www.figma.com/design/IGjwpE5m7vLaCThHgoy0cw/Relay-Runner?node-id=2139-49283)). Replace the placeholder `WorkspaceTabView` from RR-533, using its design-system components and the kit's workspace API from RR-532 (`workspace_command` `list` and pushed `workspace_state`).

- Tickets are grouped under three headings in this order: In progress, Queued, Backlog. Each row shows the ticket id, its title, and the owning agent's name when it has one, laid out as in the image. An empty group is not shown.
- Above the tab bar is a horizontally scrollable strip of project tabs: "All", then one per project, styled like the agent tabs on the Agents tab. They are tabs, not filter chips. Selecting one shows only that project's tickets; the selection lasts for the app session.
- There is no page title.
- The list is requested when the tab appears and when the app returns to the foreground, updates when the Mac pushes a change, and supports pull to refresh.
- States: loading (first load only); empty ("No open tickets" in one short line); Mac unreachable (the same floating banner as the Agents tab, with the last list dimmed beneath it); an error from the Mac (one short line and a Retry).
- Read-only: tapping a ticket does nothing in this version.

## Acceptance criteria

- [ ] With a scripted `workspace_state`, tickets appear under In progress, Queued and Backlog in that order, each with id, title and owning agent, and empty groups are hidden.
- [ ] The project tab strip shows All plus one tab per project and filters the list; it scrolls horizontally when the projects do not fit.
- [ ] A pushed `workspace_state` updates the list without user action; pull to refresh re-requests it.
- [ ] Loading, empty, unreachable and error states each render as described.
- [ ] If the Mac marks the list as truncated, one short line says so at the end of the list.
- [ ] A simulator screenshot with sample data matching the reference matches `26-workspace.jpg` for layout, type, the tab strip and the absence of a page title.
- [ ] The app builds and all tests pass; grouping, filtering and state handling have unit tests against the kit's scripted transport.
