## Description

Automatically generate a descriptive title and concise summary for each saved Relay Runner note using the configured Codex or Claude CLI in an isolated, noninteractive one-shot subprocess. Trigger background work after a new note is durably saved, relevant transcript/content changes are saved, and Stop durably publishes its final transcript. Saving and Stop must not wait for generation. Present the title and summary on the existing Backlog note card and note detail, and persist both in the same project-owned Git-backed Markdown note through the canonical artifact writer.

This is the user's new automatic-title-and-summary decision, superseding the first cut's exclusion of automatic generation. It does not revive canceled RR-369. Notes keep their stable unpadded PREFIX-N IDs, immutable artifact identities, raw transcript, existing document type, and nondispatchable behavior. No new Notes column, app, foreground Relay session, interactive provider terminal, messenger, or work-ticket worker is involved in runtime generation.

## Provider commands and evidence

Verified against installed CLI help on 2026-09-22 and official documentation:

- Codex uses `codex exec`, not `codex -x`. `--output-schema <FILE>` constrains the final response; `--output-last-message <FILE>` captures it. `--ephemeral` avoids retained session files. Reuse configured authentication. Reference: https://learn.chatgpt.com/docs/non-interactive-mode
- Claude uses `claude -p` / `--print`, with `--output-format json --json-schema <schema>`; parse the `structured_output` field. Installed help also exposes `--no-session-persistence`, `--tools` and `--strict-mcp-config`. Reference: https://code.claude.com/docs/en/headless
- Reconfirm supported flags for the resolved binaries during implementation. Isolate from project instructions, inherited MCP servers and tool execution; do not enable file, shell, network research or other agent actions for this text transformation. Use supported provider controls and verify isolation. Do not use Claude `--bare` blindly: its authentication behavior differs from normal OAuth/keychain discovery. Preserve configured auth without logging credentials or launching login UI automatically.
- These are provider-backed generation calls, distinct from on-device recording/STT. Only the selected note's necessary text is supplied to the configured provider; no repository sweep or automatic injection of other notes. No live generation was performed while authoring this ticket.
