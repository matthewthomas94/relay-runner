## Description

In the current Relay Runner build, double-tapping Shift does not bring up the board. This should be treated as a regression in the app-level board trigger path, distinct from the MCP `toggle_board` route.

Investigate whether the issue is in global keyboard monitoring, permission recovery, hotkey registration, gesture detection, or board routing. The fix should preserve the existing board behavior for active workspace sessions, active single-project sessions, and the no-session state.

## Acceptance criteria

- [ ] Double-tapping Shift opens or toggles the board in a running Relay Runner session.
- [ ] If the trigger requires Input Monitoring, missing or denied permission surfaces the existing onboarding/recovery path instead of failing silently.
- [ ] The existing menu-bar board action and RelayActions `toggle_board` MCP path continue to work.
- [ ] The no-session behavior is preserved: the board trigger shows the standard "No session running" pill rather than opening a stale or incorrect board.
- [ ] Verification covers both Codex and Claude provider sessions, or documents any intentional provider-specific difference.
