## Acceptance criteria

- [ ] The adapter selects Phonon on supported macOS 15+ configurations and Parakeet on macOS 14/explicit rollback configurations through the same resolver as ordinary STT.
- [ ] Verify real FluidAudio outputs for whitespace-marked subwords, punctuation, token timestamps and confidence. Retain the existing word assembly when compatible; handle missing timing/confidence explicitly without fabricated precision or assumptions from Fermion's separate runtime.
- [ ] Convert window-relative timing to the note timeline exactly once. Assign final words by onset in the owned half-open interval; deterministic and real-output tests cover boundary words, genuine repetitions, overlap seams, punctuation and final short tails.
- [ ] Accepted audio remains durably checkpointed before acknowledgement. Pause/stop/repeated-stop, bounded queue backpressure, final retry, offline save/retry and crash/relaunch preserve every acknowledged tail and idempotent segment identity/order/content.
- [ ] New recovery journals persist backend/model identifier, runtime revision, immutable model revision and relevant decoding identity. That identity is fixed for the active recording and its pending tail across settings changes and relaunch.
- [ ] Old journals still decode and preserve already saved text. If an unsaved legacy tail lacks a model identity, expose the necessary backend choice before replay; never silently reinterpret saved text or automatically re-transcribe completed notes. Missing original assets produce a recoverable state.
- [ ] Switching from notes to a work session respects the existing finalization boundary. MeetingTranscriptProducerTests and MeetingNoteCoordinatorTests cover changed timing, journal compatibility, tail recovery, backpressure and stale completion behavior.
- [ ] Global note IDs, immutable artifact references, library location, canonical saves and post-save title/summary metadata behavior remain intact. Note-only capture does not feed the command FIFO, start Codex/Claude or the messenger, create tickets or dispatch work. Test this separation independently of the metadata lifecycle.
- [ ] Correct docs/specs/project-note-capture.md's outdated midpoint ownership description to match onset ownership, and record representative real-model replay results separately from synthetic test results.
