## Description

Implement RR-273 delivery phase 7 from RR-270's `Program/Graphify and fresh install` map and storage/privacy classification. Classify current Program and Graphify records by ownership, export every project-scoped capture-only decision, risk, idea, status, and event into deterministic `.orchestrator/program/events/` artifact records, and rebuild Graphify/search projections from registry, artifact, and local run inputs.

Retain only genuinely app-global cross-project preferences/data in application support. Raw logs, secrets, large binaries, raw audio, sensitive transcripts, and hidden reasoning stay outside Git. Export and rebuild must be journaled, idempotent, privacy-filtered, and lossless by manifest comparison.

## Acceptance criteria

- [x] A documented classification enumerates every Program/Graphify record family as project-owned durable, app-global durable, local operational, derived, or prohibited-from-Git.
- [x] Project-scoped capture-only records export to deterministic immutable event files under the RR-270 allowlist with stable IDs, project identity, schema version, privacy filtering, and idempotent writer events.
- [x] Deleting Graphify and search indexes loses no project-owned durable record; a clean rebuild from registry, artifact refs, and permitted local run inputs reproduces the expected project/ticket/run/capture graph.
- [x] App-global storage retains only explicitly justified cross-project data and local operational/run telemetry; caches and projections cannot become a second writable ticket or Program authority.
- [x] Existing duplicate, malformed, orphaned, or cross-project records fail into a reviewable migration report rather than being silently dropped, reassigned, or committed.
- [x] Raw logs, secrets, large binaries, raw audio, sensitive transcripts, and hidden reasoning fixtures are excluded or rejected before any artifact commit.
- [x] Export/rebuild can resume after interruption without duplicate events, and pre/post manifests prove all allowed project captures survived.
- [x] Codex and Claude session captures resolve through the same confirmed scope and produce equivalent durable schemas and rebuild outcomes.
- [x] Targeted capture/export/index rebuild/privacy tests pass and documentation links ownership decisions to RR-270 phase 7.
