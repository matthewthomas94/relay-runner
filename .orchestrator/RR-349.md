## Description

Add selectable GPT-6 Astra and Claude Fable 5.1 support throughout Relay Runner. The requested Claude 5.1 target is interpreted as the publicly documented Claude Code model Fable 5.1 (`claude-fable-5-1`), not invite-only Mythos. Add support without automatically switching the user's current sessions, saved defaults, Messenger workload, or worker tiers to a new flagship.

Today `services/codex_model_catalog.py` recognizes only Sol/Terra/Luna and can normalize an unrecognized GPT family to Sol. Swift model options mirror that restriction. Claude has only a generic `fable` selection across multiple allowlists. Ensure explicit selections survive config normalization, persistence, launch, and worker validation without silently substituting another family/version. Preserve existing family/alias behavior; expose a clearly versioned Fable 5.1 choice whose launch identifier is pinned rather than assuming the generic alias selects it.

Inspect the matching Swift resolver, settings/onboarding, context metadata, ProcessManager launch paths, Python config, Messenger, command_actions, orchestrator worker overrides, and directly related generated documentation. Use the smallest consistent change; do not redesign the registry, alter unrelated models, change authentication, or implement direct-provider API migration. Check CLI compatibility and explain old-client or account-access limitations honestly. Provider catalog availability is not proof of an authenticated generation.
