## Description

Build the native SwiftUI product surface against stored fixtures before live capture integration: session history, title/date metadata, local keyword search, manual Markdown notes and a timed transcript beside them. Provide provisional/final text distinctions, source labels, manual transcript correction and session-scoped speaker rename/reassignment. A source called system audio is not automatically a single remote person. Autosave manual edits through the store and preserve them when ASR or a summary is refreshed.

Expose start/stop, model/source readiness, per-source activity, finalizing, interrupted/recoverable and error states using the foundation contract; the coordinator ticket wires real capture. Include keyboard navigation, VoiceOver labels and usable long-session performance. The MVP is a notebook, not a full document workspace or agent chat. Generation, export and deletion receive dedicated entry points wired by their own tickets.

## Acceptance criteria

- [ ] A fixture-backed user can create/find/reopen a session, write and edit manual notes beside the transcript, correct text, label speakers and retain changes after restart.
- [ ] Local search covers session titles, manual notes and finalized transcripts, with results opening the matching session/time; derived indexes update after edits and exclude deleted sessions.
- [ ] A 60-minute transcript stays responsive using bounded/virtualized presentation where needed; incoming text does not steal focus or lose an active edit.
- [ ] Readiness, recording, Stop/finalizing, missing-source and recovery states match the shared state contract; no button implies capture has started before source readiness.
- [ ] Visual/keyboard/VoiceOver QA covers empty, offline, loading, long-content and error states. Private titles/text are absent from telemetry, provider prompts and Relay.
