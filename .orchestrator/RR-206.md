## Description

Make the final Shift lesson perform the action it teaches. A real double-tap Shift on the final tutorial screen should complete and dismiss onboarding, then immediately open the normal Workspace. There should be no additional completion prompt or button between the successful gesture and the usable Workspace.

Only a successful Workspace toggle should complete the tutorial. If the toggle cannot be performed, keep the final lesson visible and allow the user to try again without corrupting onboarding state.

## Acceptance criteria

- [ ] A real double-tap Shift on the final tutorial screen invokes the same Workspace toggle used outside onboarding.
- [ ] A successful toggle dismisses the onboarding surface, marks onboarding complete exactly once, and leaves Workspace visible and interactive.
- [ ] No additional completion screen, prompt, or confirmation action appears after the successful Shift gesture.
- [ ] Shift input before the final lesson cannot prematurely complete onboarding.
- [ ] An unrelated key event or a simulated keycap animation cannot satisfy the final gate.
- [ ] If Workspace cannot open, onboarding remains on the final lesson with recoverable state and a subsequent Shift double-tap can retry.
- [ ] Manual “Redo Onboarding” exercises the same final handoff without duplicating a session, corrupting the configured workspace, or leaving overlapping onboarding and Workspace surfaces.
- [ ] Codex and Claude sessions receive identical completion and Workspace handoff behavior.
- [ ] Automated tests cover successful completion, failed-toggle retry, duplicate gestures, out-of-order input, persistence cleanup, and Workspace visibility.
