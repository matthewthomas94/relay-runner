## Description

The kanban board (Backlog, Queued, In progress, Done) is unchanged. Only the Projects panel changes.

- Header unchanged: Projects title, history button, Add project menu.
- Under the header: a search field that filters the project rows by name or path as the user types.
- Project cards (`ProgramProjectCard` in `Sources/relay-runner/Board/ProgramBoardOverlayView.swift` around line 1526, including `ProjectBoardOverview` counts) become compact rows: project name, the running-session dot and reply badge as today, and the folder button that reveals the project in Finder. The general project is the first row.
- Rows toggle selection. One selected row filters the board to that project; several selected rows show all of their tickets with project context on the cards; none selected, or a Clear control, shows every project's tickets. Today's single selection (`selectedProjectPath`, `isAllSelected`, `selectAllProjects()`, `selectProject(path:)` in `Sources/relay-runner/Board/ProgramBoardStatus.swift:1554-1790`; `selectProject` in `Sources/relay-runner/Board/ProgramBoardOverlayController.swift:1124`) becomes a set of paths.
- Creating a ticket: with exactly one selected project the form uses it; with none or several the form requires choosing a project from the registered targets.
- Leave the per-row session controls alone; a later ticket removes them.
- Keep the existing scroll behaviour and update `BoardOverlayScrollViewTests` and the `ProgramBoardStatusTests` source contracts.
