## Description

When Relay Runner's sub-agent sizing policy is `Use my defaults` and the General model and reasoning effort are both `Default`, the orchestrator resolves the worker effort to the literal string `default`. The Codex worker launcher then emits `--config model_reasoning_effort=default`. Codex rejects every run with HTTP 400 because `default` is not a supported reasoning-effort enum.

This failure blocked RR-216, RR-217, RR-220, RR-221, and RR-222 before they could perform any work. The ready sweeper retried each deterministic configuration failure repeatedly, producing failed runs rather than a useful active queue.

Treat `default` as a UI/config sentinel that means the provider owns model and effort selection. Omit provider command-line overrides for sentinel values. Keep explicit supported model and effort selections working, and ensure deterministic launch-configuration errors become visible non-retryable blockers instead of consuming the retry budget in a tight loop.

## Acceptance criteria

- [ ] With Codex, `Use my defaults` plus model `Default` and effort `Default` launches a worker without `--model` and without `model_reasoning_effort=default`.
- [ ] With Claude, the equivalent configuration omits both provider model and effort overrides rather than passing literal `default` sentinel values.
- [ ] Explicit supported model and effort selections still render the correct provider-specific flags and values.
- [ ] General, messenger, implementation-worker, and review-worker launch paths use consistent sentinel normalization without changing intentional provider-specific options.
- [ ] A deterministic provider 400 caused by invalid launch configuration is not automatically retried multiple times with the identical command.
- [ ] The ticket remains visibly blocked or failed with the actionable provider error when launch configuration cannot be normalized safely.
- [ ] Sanitized run diagnostics distinguish omitted defaults from explicit overrides and never expose prompts, responses, credentials, or unrelated environment values.
- [ ] Unit tests cover default/default, explicit model/default effort, default model/explicit effort where supported, and explicit model/explicit effort for Codex and Claude.
- [ ] An integration test proves a default-configured worker reaches real agent execution rather than failing at provider request validation.
- [ ] A packaged-daemon smoke test verifies the installed Relay Runner uses the corrected launch command and does not repeat the deterministic failure.
