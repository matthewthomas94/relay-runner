## Description

Use the supplied vector artwork for the keycaps in the session-controls onboarding tutorial:

- `/Users/matthewthomas/Downloads/caps-lock.svg`
- `/Users/matthewthomas/Downloads/option.svg`
- `/Users/matthewthomas/Downloads/control.svg`
- `/Users/matthewthomas/Downloads/shift.svg`

Preserve the SVGs as vector-backed app assets rather than recreating the keycaps with SwiftUI shapes and text.

Polish the looping keycap demonstrations so every press has a continuous eased scale-down and return instead of an abrupt or linear two-state jump. For Caps Lock, slow the rhythm from the current one-second loop by adding a noticeably longer resting interval between completed presses. Keep its indicator synchronized with the demonstrated press state.

Apply the slower rhythm to the double-tap demonstrations as well. On the playback tutorial screen, animate Option and Control in sequence rather than simultaneously: demonstrate Option, pause, demonstrate Control, pause, and then repeat.

Give the Shift demonstration the same smooth easing and longer resting interval. Render the trailing slash on every tutorial instruction as a blinking cursor, using a continuous eased opacity pulse rather than a hard visible/hidden toggle.

## Acceptance criteria

- [ ] The Caps Lock, Option, Control, and Shift tutorial keycaps render from the four supplied SVG files with their original proportions and vector fidelity.
- [ ] The tutorial no longer recreates artwork already present in those SVGs with separate SwiftUI keycap shapes or labels.
- [ ] The Caps Lock keycap follows a continuous eased scale curve during both press and release, with no visible snap between scale values.
- [ ] Caps Lock press starts are separated by more than the current one-second cadence, and most of each cycle is a stable resting pause rather than continuous motion.
- [ ] Each Caps Lock press remains visually distinct, restrained, and anchored without shifting surrounding tutorial text or layout.
- [ ] The Caps Lock status light changes in sync with the demonstrated toggle and does not flicker during the eased transition.
- [ ] Option, Control, and Shift retain clearly readable double-tap demonstrations while using the supplied vector artwork.
- [ ] Double-tap demonstrations use a longer repeat interval, leaving a stable pause after each two-press gesture.
- [ ] On the playback screen, Option and Control alternate demonstrations in the order Option → Control → Option → Control; they never animate simultaneously.
- [ ] The alternating animation leaves enough time between key demonstrations for the user to distinguish the play/replay action from the cancel action.
- [ ] The Shift double-tap uses the same continuous easing and longer resting interval without changing the gesture it teaches.
- [ ] Every tutorial instruction’s trailing slash blinks as a cursor without causing text reflow or shifting adjacent keycaps.
- [ ] Cursor opacity follows a smooth eased pulse with no hard jump between visible and dim states.
- [ ] Reduce Motion presents static emphasized keycaps and does not run the looping scale animation.
- [ ] Reduce Motion keeps the tutorial cursor legible without introducing an abrupt high-frequency blink.
- [ ] Automated tests cover keycap asset selection, continuous phase boundaries, longer single- and double-tap cycles, Option/Control alternation, Shift timing, cursor easing, light synchronization, and Reduce Motion behavior.
- [ ] Visual verification confirms the animation is smooth at the app’s supported display refresh rates and onboarding window sizes.
