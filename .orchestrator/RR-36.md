## Description

Define the first Relay Runner Program Manager MVP. This is the product and architecture contract for replacing the old PM-sync/GSD-style workflow with a native program-management layer.

The spec should preserve the current per-repo `.orchestrator/` boards as the project-level source of truth, while adding a program-level view across registered projects. Include the decision that Graphify is part of the MVP in two layers: Graphify Core early as the program graph foundation, and a small code-indexing slice later as enrichment.

The worker should not implement runtime behavior in this ticket. Produce a concise spec/roadmap doc in the repo that a cold sub-agent can use to implement subsequent tickets.

Provider parity matters: Relay Runner supports Codex and Claude. The spec must explicitly say how program-management behavior, project activation, dispatch, provider health, and sub-agent status should appear for both providers, and document any intentional differences.
