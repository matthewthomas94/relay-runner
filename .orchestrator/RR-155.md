## Description

Redesign the Settings tab so it feels native to the current notched Workspace rather than a legacy macOS settings window embedded inside it. The Work tab is the visual reference: use the same continuous dark surface, restrained depth, compact typography, spacing rhythm, and clear state language.

Replace the nested `TabView` and `Form` presentation where needed. Prefer a focused two-pane settings workspace with compact category navigation, a scrollable detail area, coherent section rows, and a save state attached to the surface. Preserve all existing controls and behavior across Status, Speech-to-Text, Text-to-Speech, General, and Awareness. The standalone Settings window must remain usable, and native keyboard and focus behavior must be preserved.

This is a native macOS product surface. Do not add illustrative imagery, decorative gradients, glass-card stacks, or gratuitous motion. Reuse the Work tab's existing surface tokens and typography rather than inventing a parallel visual system.

## Acceptance criteria

- [ ] Workspace Settings uses a continuous surface aligned with the Work tab's background, border, typography, control sizing, and spacing vocabulary.
- [ ] The legacy tab-strip and grouped-form appearance is removed from the Workspace presentation.
- [ ] Status, Speech-to-Text, Text-to-Speech, General, and Awareness remain directly navigable and retain their existing behavior.
- [ ] The selected category is visually and semantically clear without relying on color alone.
- [ ] Long settings content scrolls inside the content area without moving or clipping category navigation and save controls.
- [ ] Unsaved state, Save availability, default keyboard action, and config refresh behavior continue to work.
- [ ] The standalone Settings window remains usable at its intended size and follows the same coherent component vocabulary.
- [ ] Controls expose readable labels, keyboard focus remains usable, and reduced-motion behavior is not regressed.
- [ ] Relevant tests are updated or added, and the macOS build succeeds.
- [ ] Visual verification compares Workspace Settings with Work at the same window size and confirms there is no nested-window or iframe-like impression.
