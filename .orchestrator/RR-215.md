## Description

Build the current `main` revision through the supported release packaging path and refresh the local `/Applications/Relay Runner.app` installation. This is an operational build/install task, not authorization to modify source code or packaging scripts.

## Acceptance criteria

- [ ] Confirm the repository is on `main` with a clean tracked worktree and record the source commit being packaged.
- [ ] Run `./scripts/build-dmg.sh` successfully without modifying tracked source files.
- [ ] Verify `dist/Relay Runner.app`, `dist/RelayRunner.dmg`, and the generated Sparkle zip exist and are non-empty.
- [ ] Ensure `/Applications/Relay Runner.app` is the newly built app, using the build script's supported refresh path when an installed copy already exists.
- [ ] Verify the installed bundle's identifier, executable presence, code-signature validation, and executable checksum against `dist/Relay Runner.app`.
- [ ] Do not quit or relaunch the currently running Relay Runner process as part of this ticket.
