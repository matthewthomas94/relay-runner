## Description

Relay Runner is adding an experimental input mode called **True Whisper**: when enabled, Caps Lock capture reads silently mouthed command words from the Mac camera instead of recording the microphone. This ticket brings the validated pipeline into the app package as a library and makes the app camera-capable. The settings UI (RR-451) and the Caps Lock path (RR-452) build on it.

Source: the silent lip-command spike on origin/spike/silent-lip-commands at commit 92018861 (spikes/silent-lip-commands/mac/Sources/LipCapture/). Copy the code from that pinned commit; do not merge the spike branch or PR #51 (it stays open for its owner). The pipeline is: Apple Vision face landmarks -> 6 lip-geometry channels (`LipGeometry.swift`) -> velocity features (`Features.swift`) -> DTW nearest-template classifier (`Classifier.swift`, including `Evaluation.run` leave-one-out + label-permutation test) -> `Segmenter.swift` for articulation-energy segmentation. `main.swift` holds the `Capture` class (AVCaptureSession + `VNDetectFaceLandmarksRequest`, revision 3, VGA preset, 32BGRA) and `FrameBuffer`. The spike was validated on this machine on 2026-11-03: 4 words (stop, cancel, play, replay), 10 silent takes each, leave-one-out accuracy 0.975, permutation p = 0.002.

Work:

1. **Library target `TrueWhisper`** at `Sources/TrueWhisper/`, declared in `Package.swift` like `RelayPowerHelperProtocol`, linked into `relay-runner` and into `RelayRunnerTests`. Move `LipGeometry`, `Features`, `Segmenter`, `Classifier` (Template, TemplateClassifier, Prediction, Evaluation) into it unchanged in behaviour. Keep the numeric definitions identical to the spike (the Python port in `spikes/.../python/lipspike/` on that branch is the reference); the 6 channels are width, outer_h, inner_h, outer_area, inner_area, jaw, normalised by inter-ocular distance.
2. **Template store.** Replace the spike's `Dataset` (reads `LIPSPIKE_DATASET` / `~/.lipspike`) with `TemplateStore` that loads and saves `[Template]` as JSON at `~/Library/Application Support/relay-runner/true-whisper/templates.json` (path injectable for tests). Templates contain only label and geometry frames, never images.
3. **`LipCaptureSession`** (from the spike's `Capture` + `FrameBuffer`): opens the default video device or a name-filtered one, runs Vision per frame on its own queue, and delivers `(t, geometry)` through a callback. Must be an owned object with explicit `start()` / `stop()`; stopping releases the camera. Keep the spike's fix: the owner retains the session (the output delegate is unowned). Expose a `FrameSource` protocol so RR-452 and tests can inject geometry frames without a camera.
4. **Permissions.** Add `com.apple.security.device.camera` to `scripts/relay-runner.entitlements` and `NSCameraUsageDescription` ("Relay Runner uses the camera for True Whisper, the experimental lip-reading input mode.") to the root `Info.plist`, preserving the file's key order and comments. Add a camera case to `PermissionsManager` (status + request) following the existing microphone pattern.
5. **Tests** in `tests/RelayRunnerTests/TrueWhisper*`: geometry from a synthetic landmark layout gives the expected 6 values; DTW distance of a sequence to itself is 0 and to a stretched copy is small; `TemplateClassifier` ranks a noisy copy of a template as its own label; `Evaluation.run` on two clearly separable synthetic labels reports accuracy 1.0 with p below 0.05; `Segmenter` emits one segment for a burst of motion after calibration; `TemplateStore` round-trips.

Live camera access cannot be exercised in the worker environment: macOS attributes a worker's processes to the hosting app, which has no camera entitlement until this work ships. Verify with unit tests and injected frame sources; do not add acceptance items that need a real camera.

- [ ] `swift build` succeeds for the whole package, and `swift test --filter TrueWhisper` passes with the tests listed above.
- [ ] `Sources/TrueWhisper/` contains the geometry, features, segmenter, classifier, evaluation, template store and `LipCaptureSession`; `spikes/` is not referenced by the app target.

- [ ] The existing `RelayRunnerTests` suite still passes.
