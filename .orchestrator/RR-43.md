## Description

Replace the PM-sync copy/paste loop with native Relay Runner session review capture.

At the end of a meaningful work session, Relay Runner should gather evidence from the current repo/project, ticket changes, run history, and conversation context where available, then write structured ProgramEvent/Decision/Risk/Idea/Status nodes into Graphify Core.

This ticket should not emit PM-SYNC YAML. It should directly update the native program ledger/graph.

Provider parity matters: session capture should work from Codex and Claude sessions where possible. Any provider-specific context gaps should be documented in user-facing behavior or implementation notes.

## Acceptance criteria

- [x] A native session review/capture command or tool exists.
- [x] Capture writes structured events into Graphify Core rather than producing copy/paste YAML.
- [x] Captured events can represent shipped work, started work, blockers, ideas, decisions, and notes.
- [x] Capture links events to project/ticket/run nodes when evidence is available.
- [x] The implementation does not require `.pm/project-id`.
- [x] Codex and Claude behavior is documented, including any context/history limitations.
- [x] Tests cover event creation and linking to an existing project/ticket.
- [x] The old PM-sync path is not invoked by this new capture flow.
