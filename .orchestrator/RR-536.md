## Description

The Relay Remote iPhone Settings screen (`docs/design/relay-remote-ios/27-settings.jpg`) has a Speech speed slider and an Orchestrator section (Model, Effort, Sub-agent sizing) that mirror the desktop's settings. The phone cannot change Mac settings today. RR-532 added `settings_command` and `settings_state` to the protocol and left a stub handler on the Mac. This ticket fills it in.

**Wanted**

- `settings_command` `get` returns the current values of: speech speed (the desktop's Speech Speed, 0.5–2.0 in 0.1 steps, `TTSSettingsTab.swift`), orchestrator provider, orchestrator model, orchestrator effort and sub-agent sizing (`GeneralSettingsTab.swift`). It also returns the options the desktop would offer right now: the models for the current provider, the efforts valid for the current model, and the two sizing policies, each with its display label, so the phone hard-codes nothing.
- `settings_command` `set` takes only the keys to change and saves them through the same validated path the desktop Settings and the relay-app `set_settings` tool use (`Sources/relay-runner/App/RelayAppCommands.swift`), so the Mac's Settings window and any running session react exactly as they do to a change made on the Mac. Only the five keys above are accepted from the phone; any other key is refused.
- An invalid value or an unknown key gets a `settings_state` with an `error` and the unchanged current values. Changing the model returns the effort options for the new model, and corrects the effort if the old one is not valid for it, as the desktop does.
- When one of these settings changes on the Mac while a phone is connected, the Mac pushes a `settings_state`.

## Acceptance criteria

- [ ] `get` returns the five values and the option lists, matching what the desktop Settings shows for the same configuration (tested for a Claude and a Codex provider configuration).
- [ ] `set` of speech speed to 1.3 changes the Mac's setting, persists it, and the next reply is spoken at that speed, the same as changing the slider on the Mac.
- [ ] `set` of model, effort and sizing each persist and show in the Mac's Settings window without a restart.
- [ ] `set` with an out-of-range speed, an effort not valid for the model, or a key outside the five is refused with an `error`, and nothing is saved.
- [ ] A change made on the Mac is pushed to a connected phone.
- [ ] `docs/specs/relay-remote.md` documents the keys, the validation and the push.
- [ ] `swift build`, `swift test` and `cargo test` pass.
