## Description

Expose program-level status queries over the Relay Runner MCP/voice surface.

The user should be able to ask questions such as "what are all agents doing?", "what is blocked across projects?", "what is awaiting merge?", and "what should I look at next?" The implementation should read from Graphify Core and the cross-project ingested index rather than live-grepping repos.

Keep this ticket scoped to command/tool/query behavior and text responses. The Program Board UI is a later ticket.

Provider parity matters: responses should report Codex and Claude runs consistently and should surface provider-specific health/config issues when known.

## Acceptance criteria

- [ ] Program status tools or commands exist for active work, blocked work, awaiting merge, stale runs, and project summary.
- [ ] The tools read from Graphify Core or its derived query layer, not by ad hoc live filesystem crawling.
- [ ] Responses include project names/paths and ticket IDs so work can be traced back to repo-local boards.
- [ ] Provider labels/metadata are included when runs originate from Codex or Claude.
- [ ] Voice-friendly summaries are concise and do not dump raw graph internals.
- [ ] Error behavior is clear when no projects are registered or the graph has not been indexed.
- [ ] Tests cover at least active work, blocked work, and no-projects cases.
- [ ] Existing MCP tool behavior remains compatible for current orchestrator dispatch/list/cancel flows.
