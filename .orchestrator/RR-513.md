## Description

While setting Relay Runner up on a friend's laptop, the user found that signing in to the provider (Claude or Codex) still sends people out to a separate Terminal.app window. New users shouldn't have to deal with a terminal at all. Relay Runner already has a built-in terminal, so use it.

Current state on main:
- Onboarding's sign-in button calls `AgentAuth.openLoginInTerminal(for:)` (`Sources/relay-runner/Onboarding/OnboardingView.swift` ~1482; `OnboardingController.swift` ~157 injects it). That calls `ClaudeAuth.openLoginInTerminal()` / `CodexAuth.openLoginInTerminal()` in `Sources/relay-runner/Auth/ClaudeAuth.swift`, which use AppleScript to run `claude auth login --claudeai` / `codex login` in Terminal.app, then `open -a` to bring Relay Runner back so onboarding rechecks.
- The Start Session launch script already runs `auth login --claudeai` inside the embedded terminal when the subscription gate exits 77 (`ProcessManager.claudeSubscriptionGate`, `Sources/relay-runner/Process/ProcessManager.swift` ~1666). Reuse what that does.

Change:
- Onboarding runs the provider's login command inside the app, in the embedded SwiftTerm terminal shown in or next to the sign-in step. No Terminal.app or AppleScript.
- When the login process exits, onboarding reruns the readiness check (Claude subscription gate; Codex auth check) by itself. On success it continues. On failure it shows why and offers to try again. The `open -a` return-to-app step is no longer needed on this path.
- The user can cancel the sign-in. Cancelling stops the login process and leaves nothing running.
- Codex gets the same in-app flow as Claude.
- Also update the orchestrator instructions that tell agents to open Terminal.app for `claude auth login` / `codex login` (source behind `Sources/relay-orchestrator-mcp/Instructions.generated.swift`; regenerate it, don't hand-edit). Where possible, point them at an in-app sign-in instead.
- Keep Terminal.app only as a fallback if the embedded terminal can't start, or remove it if nothing needs it. Say which in the outcome.
