## Description

Build the tutorial, screens 15–20 (`docs/design/relay-remote-ios/README.md`, section "Tutorial"; images `15-tutorial-basics.png` to `20-tutorial-all-done.png`; Figma [2139:39906](https://www.figma.com/design/IGjwpE5m7vLaCThHgoy0cw/Relay-Runner?node-id=2139-39906), [2139:39923](https://www.figma.com/design/IGjwpE5m7vLaCThHgoy0cw/Relay-Runner?node-id=2139-39923), [2139:39989](https://www.figma.com/design/IGjwpE5m7vLaCThHgoy0cw/Relay-Runner?node-id=2139-39989), [2139:41674](https://www.figma.com/design/IGjwpE5m7vLaCThHgoy0cw/Relay-Runner?node-id=2139-41674), [2139:41749](https://www.figma.com/design/IGjwpE5m7vLaCThHgoy0cw/Relay-Runner?node-id=2139-41749), [2139:44039](https://www.figma.com/design/IGjwpE5m7vLaCThHgoy0cw/Relay-Runner?node-id=2139-44039)). It is a port of the desktop's `Sources/relay-runner/Onboarding/OnboardingSessionControlsTutorial.swift` to the phone's controls. Replace the placeholder body of `TutorialView` from RR-533, using its hero layout and inline chips, and the real dock from RR-540.

**Steps**

1. "Now let's learn the basics /", shown while speech recognition gets ready (model download and warm-up) and an agent is available. Moves on by itself when ready.
2. "[mic Hold to talk] & say hi /". Advances when the user starts holding the real Hold to talk button.
3. "Now release to send /". The transcript fills the real text box and the orange glow shows. Advances when the user releases and the message is sent.
4. "Wait for a reply, then tap [▶ Play] /". The reply is queued, not auto-played, for this step whatever the user's setting. Advances when the user taps Play.
5. "Tap [■] to stop playback /". The purple glow shows while the reply plays. Advances when the user taps Stop, or when the reply finishes by itself.
6. "You're all done /", held briefly, then straight into the app. There is no Workspace step.

**Rules**

- Each step advances only on the user's action (or the automatic conditions named above). There are no Next buttons.
- The real dock and tab bar sit at the bottom, as in the app. The control the current step targets stays fully lit; every other control, and the tab bar, is dimmed to 30% and does not respond.
- The chips in the hero text look like the real controls and use the same outline icons. The word "Hold" is not repeated before the "Hold to talk" chip. Line breaks follow the images exactly, so no single word sits on a line of its own.
- Hero text stays at the same position as on every onboarding screen.
- "Skip →" top right ends the tutorial and enters the app at any step.
- The tutorial talks to the agent the Mac reports as running; if none is running it starts George (start with no project). If the Mac is unreachable or no reply arrives within about 30 seconds on step 4, show one short line saying so and offer Skip as the way on; do not trap the user.
- Finishing or skipping marks onboarding finished. The tutorial does not show again unless the app is reinstalled.

## Acceptance criteria

- [ ] Skip at any step enters the app and the tutorial does not return on relaunch.

- [ ] The app builds and all tests pass; the step machine has unit tests driven by faked voice and session events, including the timeout and skip paths.
