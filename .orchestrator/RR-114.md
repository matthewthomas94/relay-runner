## Description

Relay Runner has replaced the legacy PM-sync copy/paste workflow with native Program Manager session capture. Remove remaining product surfaces that install, advertise, or preserve PM-sync skills as an active workflow.

Keep the cleanup safe: do not delete user `.pm/` project data automatically. Historical docs may mention PM-sync only as a deprecated or replaced workflow, not as something users should invoke.

## Acceptance criteria

- [ ] Relay Runner install/reinstall paths remove or stop installing legacy PM-sync Codex/Claude/agent skills and commands where those are owned by the old workflow.
- [ ] Current Relay Runner guidance for Codex and Claude directs program tracking to native `session_capture` only and does not suggest `/pm-sync` or PM-sync YAML.
- [ ] Historical docs or verification notes that still mention PM-sync clearly frame it as legacy/replaced; no current setup, README, AGENTS, CLAUDE, service instruction, or generated MCP instruction presents it as an active workflow.
- [ ] Existing `.pm/` directories and `.pm/project-id` files are not deleted automatically; any cleanup is limited to the legacy PM-sync skill/command surfaces.
- [ ] Tests or script checks cover the cleanup/guidance behavior for both Codex and Claude where applicable.
- [ ] Verification includes the relevant Swift/Python/script tests plus an `rg` pass showing only intentional legacy references remain.
