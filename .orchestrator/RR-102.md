## Description

Verify the exact model and reasoning-effort controls available to Relay Runner worker processes before enforcing a permanent sizing check.

Current findings:

- Codex docs say custom agent files can set `model` and `model_reasoning_effort`; omitted values inherit from the parent session.
- Current `codex exec --help` exposes `--model` and `--config key=value`, which means Relay Runner should be able to launch external Codex workers with an explicit model and `model_reasoning_effort` override.
- Relay Runner currently starts Codex workers with `codex exec --json --ephemeral --dangerously-bypass-approvals-and-sandbox --dangerously-bypass-hook-trust` and does not pass a model or reasoning-effort override.
- Relay Runner currently starts Claude workers with `claude -p --dangerously-skip-permissions --verbose --output-format stream-json` and needs a separate verification path for Claude model selection.

Primary sources:

- https://developers.openai.com/codex/subagents
- https://developers.openai.com/codex/concepts/subagents
- https://developers.openai.com/codex/cli/reference
