## Description

Establish whether Phonon 2 can safely replace Relay's default English recognizer through its existing FluidAudio integration. Relay currently resolves FluidAudio v0.13.6 (57551cd90e0bbec342766244358bcf08afb05290); evaluate v0.17.5 at 0b1f46289fe27d95b5e66ad8be46e64f5ee02ae7, which exposes AsrModelVersion.phonon2. Use a focused harness or prototype and an evidence report. This is implementation mode because the harness and report are committed; it is not a read-only spike.

The agreed policy is Parakeet on macOS 14, Phonon 2 as the default English model on macOS 15+ after validation, and preservation of explicit Parakeet v3 selections for multilingual use. Keep the app deployment target at macOS 14. Do not switch production defaults in this ticket.

Inspect Package.swift, Package.resolved, STT/STTEngine.swift and Notes/FluidAudioMeetingTranscriber.swift under Sources/relay-runner. Review upstream API, decoding, normalization, token timing, resource and binary changes, including NemoTextProcessing. Use the default Neural Engine model from FluidInference/phonon-2-coreml; resolve an immutable model revision and selected file hashes. Do not introduce a separate Fermion runtime, general backend framework, custom downloader, or alternate encoder.
