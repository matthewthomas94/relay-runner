## Description

Relay Runner now has four fixed agents (see RR-519): Puck, Isabella, George and Sky, in that order, at most four running at once. Stopping an agent keeps its conversation and starting it again resumes it. Work style is a per-agent setting in Settings (see RR-522), and the Start Session button no longer has a work-style menu.

The user's rule: a session never starts without the user choosing which agent it is. RR-519 left interim defaults in place (Add controls start the next free agent; Start buttons start the most recent agent or Puck). This ticket replaces them with an explicit choice.

### Code (verify before relying on it)

- `ProgramSessionPrimaryButton` in `Sources/relay-runner/Board/ProgramBoardOverlayView.swift`, shown in the Workspace board's Done column and reused by the Terminal empty state in `Terminal/EmbeddedTerminal.swift`.
- `ProgramAddProjectMenu` in the same file: one button whose click always opens a menu (`SettingsDropdownPresenter` + `SettingsMenuOptions`), with no separate primary action. This is the behaviour the user asked to copy.
- `WorkspaceAddTabButton` in `Terminal/WorkspaceTerminalSurface.swift` (the tab strip's "+"), and Cmd-T / Cmd-W in `Board/PMTabShortcut.swift`.
- `start_session` in `Sources/relay-app-mcp/AppTools.swift`, handled in `Sources/relay-runner/App/RelayAppCommands.swift` through `RelaySessionControl.start(projectID:)` in `Remote/RelaySessionControl.swift`.
- Relay Remote `SessionCommand` / `SessionState` in `Sources/RelayRemoteProtocol/Frames.swift`, mirrored in `rust/relay-rs/src/remote/protocol.rs` and `ios/RelayRemoteKit`.
- Other callers of `newSession`: the double-tap Alt session prompt and the Notetaker hand-off (`transitionFromNoteToSession`) in `AppState.swift`.

### What to build

1. **Start Session button (Workspace Done column and Terminal empty state).** With no session running, clicking the button always opens a menu of the four agents, built the way `ProgramAddProjectMenu` is. Choosing an agent starts it, resuming its last conversation. The button has no direct start action. While a session is running the button keeps its End Session behaviour.
2. **Tab strip.** The terminal tab strip shows one tab per running agent, named and ordered as in the table. A tab's x stops that agent. The "+" opens the same agent menu listing only the agents that are not running; choosing one starts it. With all four running the "+" is disabled and its reason reads "All four agents running".
3. **Shortcuts.** Cmd-T opens the "+" menu instead of starting an agent. Cmd-W keeps stopping the active agent with its existing confirmation rules.
4. **`start_session` tool.** It takes a required `agent` (one of the four slugs or names). Without it, or with an unknown value, the call is refused with a message listing the four agents and which are running. Update the tool description and the Relay App instructions so a PM asks the user which agent when they have not said.
5. **Paths that cannot show a menu.** Relay Remote's `SessionCommand` gains an optional `agent` and `SessionState` reports the active agent and the running ones, in the Swift, Rust and iOS copies of the protocol. A Remote start without `agent` (an older phone build), the Notetaker hand-off and the session prompt start the most recently active agent, or Puck if none has run. These are the only paths allowed to start without an explicit choice.
6. **Remove the interim defaults** from RR-519 everywhere else.
