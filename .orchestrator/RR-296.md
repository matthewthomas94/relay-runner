## Description

Implement the approved V2 artwork for the neutral white **Working** loader in Relay Runner’s native notch renderer. Use `/Users/matthewthomas/Downloads/Working V2 - Animated.svg` as the design source; its verified SHA-256 at ticket authoring is `a647a415d95415dada3e7ce9e97a674d07b762859b48a2d48732c6e25fdf8866`. Translate the SVG geometry and animation into Swift rather than loading the SVG at runtime.

Scope this ticket to the Working state only: four 3-point white dots rotate counterclockwise from 0 to -18.85 radians over a 2-second linear cycle. Keep **Not working** as the same static neutral four-dot geometry, and preserve the existing orange **Listening** and blue **Playing** geometry and 0.6-second motion. When Reduce Motion is enabled, render the static neutral geometry without continuous animation. Do not package, install, replace, or launch `/Applications/Relay Runner.app` as part of this implementation ticket.
