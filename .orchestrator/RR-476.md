## Description

Background: RR-448 (done) scoped porting the Python services in `services/` to Rust. Read its `## Spike report` first; it holds the inventory, interface list, evidence and staged plan. Use `scripts/relay-ticket-history show RR-448` if the ticket has been archived.

RR-448 found that the running voice bridge loads `espeakng_loader/libespeak-ng.dylib` (espeak-ng, GPL-3.0) and uses `phonemizer-fork` 3.3.2 (GPL), both installed as dependencies of `kokoro-onnx` by `pip install -r services/requirements.txt` on first run. `THIRD_PARTY_NOTICES.md` (around lines 37-52) lists ONNX Runtime, kokoro-onnx and the Kokoro model only, and the project licence is MIT. These packages are downloaded onto the user's machine at install time; they are not inside the signed app bundle.

- Add `espeakng-loader`, espeak-ng and `phonemizer-fork` to `THIRD_PARTY_NOTICES.md` with their versions or version ranges, licences, upstream links, and a plain statement of how they reach the user's machine (installed by pip into the services venv at first run, not bundled).
- Check the other transitive packages that `pip install -r services/requirements.txt` brings in and list any other copyleft licence found. Record the full resolved list and licences in the run log.
- If `tests/test_public_release_docs.py` or a similar test checks the notices, extend it so a new copyleft transitive dependency is caught.

Do not change the speech stack here; replacing it is a separate ticket. Do not give legal advice in the document: state facts and licences only.
