## Description

Restore the canonical foreground voice-to-work lifecycle after RR-334 returns the runtime to health. Preserve exact command and intent identity where recovery is safe, never duplicate an ambiguous or completed effect, and make the user’s next action clear when speech was lost before a recoverable command existed.

The continuity agent remains silent throughout. Deterministic Relay-owned status may say recovery is underway, the canonical messenger and foreground PM regain authority only after health is proven, and source or project work continues through the original authorized ticket or command path.

## Acceptance criteria

- [x] Recovery distinguishes at least four durable phases: speech lost before a transcript or command existed, transcript captured but not delivered, command delivered but unclaimed, and command claimed, in flight, or completed.
- [x] If speech content was never captured durably, Relay restores listening and asks the user to repeat without inventing, reconstructing, or replaying content.
- [x] Captured but undelivered or provably unclaimed commands may resume exactly once with their original command, intent, ordering, and recovery-generation identity through durable deduplication.
- [x] Claimed, ambiguous, externally effectful, or completed commands are never automatically replayed; Relay reattaches to authoritative state or escalates for foreground review.
- [x] Foreground reply and TTS ownership return to the canonical messenger and PM only after component health and session registration remain stable for the defined window; the continuity agent never speaks or becomes command authority.
- [x] Existing accepted ticket and worker authorizations survive additive recovery, while replacement, redirect, interrupt, and cancellation semantics still revoke only their declared scope.
- [x] Tests cover each lifecycle phase, recovery during provider and bridge restarts, duplicate delivery pressure, stale completion, ordered queued turns, and a deterministic please-repeat outcome for unrecoverable speech loss.
