## Description

Fix a mounted regression where an ordinary orchestrator progress reply reaches the **Double tap Control to cancel** playback pill already truncated with an ellipsis. The captured pill displayed `I found three verification-blocked tickets. I am separating their real-world evidence require…` instead of the complete public progress text.

RR-298 preserved full detail for protected lifecycle outcomes while deliberately retaining a compact ordinary-progress path. Extend the contract so compact notch/status text can remain bounded without irreversibly shortening the only user-visible playback/display copy. Also keep progress semantically distinct from an authoritative final: if a final is absent or suppressed, Option replay must not relabel an ellipsized progress fragment as the completed answer.

- [x] The event contract carries separate bounded summary and complete validated public detail fields for ordinary audible progress, as it already does for protected lifecycle detail, without exposing private provider or transcript content.
