## Description

Spec: `docs/specs/relay-remote.md` (Relay Remote: iOS voice over SSH), committed as `2a64cc0d` on branch `claude/ios-relay-ssh-tcp-spec-ddb8f2`. The spec is not on `main` yet; if the file is missing from your worktree, read it with `git show 2a64cc0d:docs/specs/relay-remote.md`. Read these sections first: Wire protocol, Architecture.

Define the Relay Remote wire protocol once, in code, for both ends: a SwiftPM library target `RelayRemoteProtocol` (platforms macOS 14 and iOS 18) in this repository's `Package.swift`, and a Python twin `services/relay_remote_protocol.py` for the bridge. Both must agree byte for byte on shared golden vectors.

Framing: newline-delimited UTF-8 JSON, one object per line, 64 KiB maximum per line, enforced on encode and decode. Frames the Mac sends carry a per-device monotonically increasing `seq`; frames the phone sends carry a `client_id` UUID so a retry after a reconnect never becomes a second command.

Phone to Mac: `hello` (`protocol`, `device_id`, `device_name`, `app_version`, `resume_after_seq`), `utterance` (`client_id`, `text`, `captured_at`), `control` (`client_id`, `action` in stop, interrupt, cancel, play, replay), `ack` (`seq`, `played`), `ping` (`t`).
Mac to phone: `welcome` (`protocol`, `session_state`, `server_seq`, `resumed_from`, `dropped`), `accepted` (`client_id`, `relay_command_seq`, `relay_command_id`), `speech` (`seq`, `kind`, `source`, `text`, `relay_command_seq`; `kind` and `source` take the same values as `SpeechIntent` in `services/speech_coordinator.py`), `speech_control` (`seq`, `action` in stop, skip; `reason`), `status` (`seq`, `text`), `error` (`code`, `message`), `pong` (`t`). The spec's Wire protocol section shows one example of each.

Both implementations provide: typed encode and decode with validation and a clear error for unknown types or missing fields; the 64 KiB limit; a per-device `seq` counter; `client_id` de-duplication within a bounded window; and a replay buffer holding the last 200 Mac-to-phone frames or five minutes, whichever is smaller, trimmed by `ack` and replayed in order from `resume_after_seq`. When `resume_after_seq` is older than the buffer, `welcome` carries `dropped: true`.

Golden vectors: JSON files under `Tests/RelayRemoteProtocolTests/Vectors/` declared as SwiftPM test resources; the Python tests in `tests/test_relay_remote_protocol.py` read the same files. Out of scope: sockets, SSH and bridge integration (RR-423, RR-425, RR-428).
