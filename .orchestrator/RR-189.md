## Description

Change the Settings `Redo Onboarding…` action from a focused setup replay into a faithful first-run test experience. Manual redo must start with the same cinematic intro a pristine automatic launch uses, then proceed through the existing live permission, coding-agent choice, selected-provider runtime preparation, selected-provider login, and final workspace-selection sequence.

While a pristine launch or manual first-run redo is active, Relay Runner's ordinary app shell must be unavailable. Starting redo from Workspace Settings must dismiss the Workspace overlay, and attempts to open Workspace, its Terminal tab, or Settings through the menu, notch, hotkey, or registered Settings route must be ignored until onboarding finishes. Required external surfaces opened by onboarding itself—macOS System Settings, provider login in Terminal, and the workspace folder picker—remain available. Preserve current permissions, authentication, provider, workspace, model, effort, and completion flags until the user explicitly acts in the corresponding onboarding step.

Implement this inline on the current branch as explicitly requested; do not dispatch a worker.

## Acceptance criteria

- [ ] `Redo Onboarding…` begins with the same cinematic intro and pacing as a pristine first launch, respecting the same Reduce Motion behavior.
- [ ] After the cinematic, manual redo runs the complete current sequence: missing permissions → coding agent → runtime → login → workspace last.
- [ ] Workspace is dismissed immediately when redo starts, and Workspace, Terminal, and Settings entry points remain locked until onboarding completes.
- [ ] Onboarding-owned System Settings, external Terminal login, and workspace picker handoffs continue to work while the shell is locked.
- [ ] Repeated redo activation while the flow is active is idempotent.
- [ ] Merely starting redo does not clear existing permission, auth, provider, workspace, model, effort, or onboarding-completion state.
- [ ] Focused lifecycle/shell-lock tests and the full `swift test` suite pass.
- [ ] A release DMG is built and its installed app bundle is verified before launch.
