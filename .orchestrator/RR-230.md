## Description

Set Relay Runner's default text-to-speech playback speed to **1.3x** for new
installations and configurations where no speech rate has been saved.

The Swift `TtsConfig` and Python service defaults currently use `1.1`, while
some defensive TTS worker fallbacks still use `1.0`. Establish one consistent
`1.3` default across configuration creation, loading, the Settings UI, and the
running speech worker. Preserve every existing explicit user value, including
older `1.0`, `1.1`, or custom rates; this is a default change, not a forced
migration.

Kokoro synthesis must continue using `speed=1.0`, because Relay Runner applies
the configured multiplier during `afplay` playback to avoid the documented
Kokoro ONNX integer-truncation behavior. Change the configured playback-rate
default, not the synthesis path.

## Acceptance criteria

- [ ] A fresh app configuration persists `tts.rate = 1.3`.
- [ ] Python services loading a missing configuration or a `[tts]` section
      without `rate` resolve the speech rate to `1.3`.
- [ ] The TTS worker uses `1.3` for playback when no explicit rate exists and
      passes that multiplier through the existing `afplay -r` path.
- [ ] The Speech Speed control initially displays `1.3x` for a fresh
      configuration and continues to save user changes normally.
- [ ] Existing saved rates are preserved exactly and are not rewritten to
      `1.3` during load or migration.
- [ ] Legacy WPM-to-multiplier migration remains unchanged.
- [ ] Kokoro synthesis remains fixed at `speed=1.0`; no fractional multiplier
      is passed into the affected ONNX synthesis path.
- [ ] Focused Swift and Python tests cover fresh defaults, missing-rate
      fallback, explicit-value preservation, Settings display, and worker
      playback behavior.
- [ ] The full relevant Swift and Python test suites pass.
