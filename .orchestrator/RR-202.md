## Description

Add a `Continue` button beside the existing `Browse…` button on the full-screen `Choose your workspace` onboarding screen. The new action should let users accept the workspace path already displayed without reopening the folder picker.

Keep `Browse…` available for changing the path. Continuing should follow the same onboarding path as a successful folder selection and should not alter provider-specific behavior.

## Acceptance criteria

- [ ] The `Choose your workspace` screen displays `Continue` beside `Browse…` in the existing workspace control row.
- [ ] Selecting `Continue` accepts the currently displayed workspace path and advances to the next onboarding state without opening the folder picker.
- [ ] When no workspace has been configured, `Continue` accepts the same home-folder fallback currently shown in the path field.
- [ ] `Browse…` retains its current folder-selection and cancellation behavior.
- [ ] The new button has an appropriate accessibility label and supports the screen’s primary keyboard action.
- [ ] The two actions remain legible and aligned at supported onboarding window sizes.
- [ ] Fresh first-run onboarding and manual “Redo Onboarding” use the same workspace-selection behavior.
- [ ] Automated tests cover continuing with an existing path, continuing with the home-folder fallback, and browsing or canceling without unintended advancement.
