## Description

Simplify the command acknowledgement UI. The separate acknowledgement pill and return message are not carrying enough value to justify the extra surface area, but the short acknowledgement text in the notch is still useful feedback after a command is accepted.

The desired behavior is to keep a concise notch acknowledgement, such as "Acknowledged", while removing the standalone acknowledgement pill and any redundant return message associated with that acknowledgement flow.

- [ ] The standalone acknowledgement pill no longer appears after a voice command is accepted.

- [ ] The acknowledgement flow does not show a redundant return message or duplicate acknowledgement surface.
- [ ] Listening, working, response-ready, and TTS control states continue to render normally.
- [ ] Codex and Claude sessions use the same acknowledgement behavior unless an intentional provider difference is documented.
- [ ] Add or update regression coverage for the acknowledgement UI state.
