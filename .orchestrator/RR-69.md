## Description

Build the current Relay Runner app from the local `main` checkout and place the resulting DMG in `~/Downloads` for the user.

Use the existing packaging script:

```bash
./scripts/build-dmg.sh
```

The script supports unsigned local builds when `SIGN_IDENTITY` and `NOTARY_PROFILE` are unset. Do not make source changes unless the build fails for a concrete repo issue; if that happens, keep the fix minimal and explain it in the run log.

After the build completes, copy the newest generated `.dmg` from `dist/` to `~/Downloads/`.

## Acceptance criteria

- [ ] `./scripts/build-dmg.sh` completes successfully from the repo root.
- [ ] The generated Relay Runner `.dmg` is copied to `~/Downloads/`.
- [ ] The final run log includes the copied DMG path and a size or timestamp check proving it exists.
- [ ] Any build failure is reported with the failing command and the relevant error excerpt.
