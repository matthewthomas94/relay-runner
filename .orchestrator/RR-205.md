## Description

Make the recording and playback tutorial steps form one coherent real interaction. When the user records and sends the instructed greeting, the active coding-agent session must return a short audible response, such as `Hello, how are you?`, through the normal Relay response and deferred-playback pipeline.

Do not advance to the playback lesson merely because the user’s transcript was delivered. Advance only after a nonempty response is available to play, so the next instructions always have real audio behind them.

Teach and verify the complete playback sequence:

1. Double-tap Option to play the response.
2. Double-tap Option again to replay it.
3. Double-tap Control while the replay is active to cancel it.

The tutorial should reach the final Workspace lesson only after that ordered sequence succeeds.

## Acceptance criteria

- [x] Sending the instructed greeting during the recording lesson reaches the active Codex or Claude session as a real user message.
- [x] The provider returns a short, user-facing response through the normal Relay response path; the tutorial does not rely on silent or synthetic gesture callbacks.
- [x] The recording lesson does not advance to playback until a nonempty response is ready in the deferred-playback pipeline.
- [x] The playback lesson always has a current tutorial response available when it first appears.
- [x] The first Option double-tap plays the response, and the tutorial remains on the playback lesson after playback completes.
- [x] A second Option double-tap replays the same response and advances the interaction gate to await cancellation.
- [x] Control completes the lesson only when it cancels the active replay; early, out-of-order, or idle cancellation does not advance.
- [x] The successful play → replay → cancel sequence advances to the final Workspace lesson exactly once.
- [x] A missing, empty, failed, or timed-out provider response produces a recoverable retry state rather than a playback lesson with nothing to play.
- [x] Resume behavior never treats an unavailable or stale response from an earlier session as the current tutorial response.
- [x] Codex and Claude follow equivalent response-readiness and gesture-gating behavior.
- [x] Automated tests cover response readiness, empty and failed responses, the ordered play/replay/cancel gate, out-of-order gestures, resume safety, and provider parity.
