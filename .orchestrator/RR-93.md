## Description

The Relay Runner menu bar icon can get lost when the user's menu bar is crowded. Add a lightweight dynamic-island-style status surface near the camera notch so the user can tell at a glance whether Relay Runner is active.

The requested shape is a small status icon on the right side of the camera bump/notch, reusing the Relay Runner icon if that is the simplest coherent approach. When Relay Runner turns on or an active session starts, the indicator should pull out from the notch and then remain present while Relay Runner is active. The active state should visually match the existing orange tray/menu bar active indication so the two surfaces communicate the same state. Keep this as an app status affordance, not a full replacement for the menu bar menu.

The implementation should handle Macs without a notch and multi-display setups deliberately. If a notch-adjacent position is unavailable, choose a restrained fallback or document why the surface is hidden rather than placing it somewhere surprising.

## Acceptance criteria

- [ ] A compact Relay Runner status icon can appear to the right of the camera notch on supported displays.
- [ ] When Relay Runner becomes active, the icon pulls out from the notch area and then remains visible while Relay Runner is active.
- [ ] The status icon uses the same active/inactive source of truth as the existing menu bar or tray status.
- [ ] Active state uses the same orange visual language as the current tray/menu bar active indication.
- [ ] When Relay Runner is inactive, the surface retracts or clearly leaves the active-present state without implying the app is listening.
- [ ] The surface does not occlude menu bar items, system indicators, or the camera notch area.
- [ ] Multi-display and non-notched Mac behavior is handled intentionally and documented in code, tests, or verification notes.
- [ ] The menu bar icon and menu behavior continue to work unchanged.
- [ ] Add focused Swift tests where state/placement logic is unit-testable, plus manual verification notes for notch-display positioning if direct UI automation is not practical.
