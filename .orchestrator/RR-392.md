## Description

Prevent the central Relay folder from growing indefinitely once optional remote storage is configured. Implement a configurable local cache budget and retention policy for notes and general-task files, with a small durable catalog and on-demand retrieval of archived content. The existing notes store retains Git history: deleting materialized files alone does not reclaim historical blobs. Measure and bound the whole managed footprint, including Git object data and temporary downloads. Focus retention on the accumulated size of notes, task documents and their version history.

## Acceptance criteria

- [x] Expose storage usage and a configurable budget/retention policy with documented defaults. Distinguish evictable synced content, pinned/active content, unsynced content and unavoidable metadata.
- [x] Evict a local copy only after verifying its exact immutable remote revision/blob. Preserve the last recoverable copy on auth, network, conflict, checksum or partial-publication failure.
- [x] Keep active tasks, in-progress recordings and unsynced/pinned files available; any temporary budget overage has a visible cause and resumes cleanup once safe.
- [x] Archived notes and files remain searchable by stable identity and can be fetched on demand with bounded temporary storage and content verification; interrupted downloads retry without duplicate artifacts.
- [x] Demonstrate actual disk reclamation including .git/object storage, not only fewer visible Markdown files. Avoid a permanent full-history clone that defeats the configured budget and do not rewrite or purge remote user history automatically.
- [x] Without a configured remote, preserve unique local content and explain capacity pressure; offer explicit export/delete decisions rather than silently deleting files to enforce a hard cap.
- [x] Regression and recovery checks cover interrupted upload/eviction, offline access, corrupt/missing remote blobs, destination changes, pinned files and restored note identities. Report installed storage and retrieval validation separately.

## Implementation and verification

Implemented inline with Codex and its subagents. Personal storage defaults to a configurable 256 MiB cache and 30-day recent-use retention, with usage including cached versions, temporary downloads, metadata, legacy Git objects and protected unmanaged task data. Exact immutable remote commit/tree/blob plus SHA-256/size verification and a local rehash are required before eviction. Active, recording, pinned, edited and unsynced content remain protected. Archived identities remain searchable and support bounded verified on-demand retrieval. Local-only capacity pressure is explained and never deletes a unique copy to force a hard cap.

Legacy central notes migrate only after approval and a complete verified Git bundle plus immutable versions; cleanup revalidates the unchanged legacy head after interruption.
