## Description

The Relay Runner tray/menu bar menu can become too wide when `serviceLifecycleMessage` contains a long error such as `Bundled service refresh failed: relay-orchestrator --restart-if-idle failed with exit code 1.` The screenshot from June 12, 2026 shows the entire menu stretched across much of the screen.

Keep the menu compact while still surfacing the actionable state. The long service lifecycle message should not determine the menu width. Prefer a short visible label plus a way to inspect the full detail, such as a tooltip, secondary details window, or truncated text that remains readable.

## Acceptance criteria

- [ ] The tray menu remains compact when `serviceLifecycleMessage` contains a long string.
- [ ] The user can still discover the full service lifecycle error text without needing logs.
- [ ] Menu labels such as Start Session, Record, Replay, Show Board, Show Status, Settings, Check for Updates, and Quit remain readable.
- [ ] Add or update a focused Swift test for the formatting/truncation helper or menu-state model if the UI text is factored outside the view.
- [ ] Verify with `swift test --skip-update`.
