## Description

Deleted tickets still appear in the Program Board. The screenshot from June 12, 2026 shows `RR-78 test` in Backlog even though the detail panel says the ticket file was not found at `.orchestrator/RR-78.md`.

Fix Program Board data loading and refresh so missing ticket files are not rendered as live cards. Stale run-history or cached program-status data must not keep deleted ticket cards visible in the board lanes. If a detail view is already open when the file disappears, it should close, refresh, or show a short stale/deleted state without leaving the card in the lane.

## Acceptance criteria

- [ ] A ticket whose `.orchestrator/<id>.md` file no longer exists is not shown as a normal Program Board card.
- [ ] Program Board refresh removes deleted tickets from all lanes in all-project and filtered-project mode.
- [ ] Run-history records for deleted tickets do not recreate phantom cards.
- [ ] If the selected detail ticket is deleted, the detail panel updates to a clear deleted/missing state or closes cleanly.
- [ ] Project Board behavior for deleted tickets is not regressed.
- [ ] Add Swift and/or Python tests that reproduce a deleted ticket still appearing from stale program data.
- [ ] Verify with `swift test --skip-update` and `python3 -m unittest discover tests` if daemon code is touched.
