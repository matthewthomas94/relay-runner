Two voice commands from the user on 15 November 2026 never reached the foreground session, and the user got no reply or notice.

A moment later the state file listed 375 as current and deliverable. Confirm the cause before fixing.
2. **Never queued.** Command 376 arrived at 21:01:31 while a typed (manual) turn was active. The state file lists it as deliverable with its intent `pending`, but the terminal recorded no `queued` event for it. Find out whether it waits for the typed turn to end or is lost, and make sure it is delivered.

In both cases nothing told the user. A command that is truly superseded may be dropped, but the drop must be visible (a trace or reply), and a current command must never be dropped.
