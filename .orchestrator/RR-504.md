## Description

Follow-up from the RR-501 spike (run 380); read its findings in RR-501 before starting.

At spawn, store the pgid and the process start time (`lstart`) with the pid in the runs table. Use them in `process_is_alive` and `run_abandoned`. Fix the unverified SIGTERM in `reconcile_on_startup` (`runs.rs` around lines 472-477) so it signals only a process whose identity still matches. At startup, `killpg` verified worker groups left by a previous daemon.

## Acceptance criteria

- [ ] The runs table records pgid and start time for new runs; older rows without them still work.
- [ ] A reused pid with a different start time is never signalled (covered by a test).
- [ ] Workers from a previous daemon whose identity matches are stopped at startup.
