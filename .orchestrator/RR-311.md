## Description

Extend the existing recoverable fresh-install tooling into explicit reset profiles and a deterministic evidence-capture workflow. The profiles must distinguish safe Relay-owned reset, separately confirmed voice-model/provider-integration reset, and a clean-user or VM validation level. Do not claim that a local reset recreates a brand-new macOS user when TCC, Keychain, notification authorization, Gatekeeper, or shared dependency caches remain.

Provide a practical second-Mac procedure based on disposable standard macOS users: retain an untouched administrator account, create a fresh test user, exercise installation/onboarding/first Workspace setup, collect the safe evidence bundle, then remove the test user with its home folder. VM snapshots are an optional faster reset route.

## Acceptance criteria

- [ ] The harness has a read-only preview and a separate explicit execution confirmation for every destructive profile.
- [ ] Relay-owned Application Support, preferences, caches, launch agents, and exact Relay temporary artifacts are inventoried, validated, and recoverably reset only after verified quiescence.
- [ ] Voice models and named provider integrations require separate opt-in, are backed up or recoverable where appropriate, and never delete broad provider directories, global caches, credentials, repositories, or developer build state.
- [ ] The harness reports the state it cannot reset, including TCC, Keychain, notifications, Gatekeeper, and shared machine state, and directs those checks to a clean user or VM.
- [ ] Reinstall and first-run evidence capture records installer context, runtime version, startup outcome, and any generated incident/support bundle without capturing private source content.
- [ ] Automated tests cover preview/execute gating, interrupted recovery, refusal around active processes, profile boundaries, and protection of non-Relay-owned paths.
- [ ] Documentation provides a repeatable second-Mac clean-user procedure and a VM-snapshot alternative, including a checklist for both Codex and Claude setup states.
