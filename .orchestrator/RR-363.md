## Description

Create the smallest native SwiftUI macOS app skeleton for RR-359's standalone meeting product. Pin the accepted platform/dependencies, add ordinary build/test commands and define session, capture-epoch/media-chunk, timed transcript segment, session-scoped speaker, manual-note, derived-summary and resumable-job contracts. Use UUID identities, sample-based capture positions mapped to a monotonic session timeline, explicit partial/final transcript semantics and generation/cancellation tokens. Raw ASR and user edits are separate; summaries reference input revisions.

Expose only the narrow persistence, capture, transcription and UI seams required by the next tickets, with synthetic in-memory fixtures. No generic plugin framework, cloud/sync schema, Relay daemon dependency or production recorder. Define idle/preparing/recording/stopping/finalizing/complete and interrupted/failed outcomes. Application Support storage must be outside all repositories; the new app is the sole writer. Reserve an open-app/open-session UUID contract for Relay, with no recording or content commands.
