## Description

Add an `End Session` control to the Program Board in the same header area where the existing `Start Session` button appears.

The current Program Board header hides `Start Session` while `hasActiveSession` is true, leaving no board-local way to end the active Relay Runner voice session. When a session is active, show an `End Session` button in that location and wire it to the same session-ending behavior used by the menu bar `End Session` item.

Keep the scope focused on the Program Board control and lifecycle wiring. Do not change ticket dispatch, board routing, voice command capture, or the existing Start Session behavior when no session is active.

Likely touch points:

- `Sources/relay-runner/App/AppState.swift`
- `Sources/relay-runner/Board/ProgramBoardOverlayController.swift`
- `Sources/relay-runner/Board/ProgramBoardOverlayView.swift`
- focused Relay Runner tests for Program Board header/session controls where practical

## Acceptance criteria

- [ ] When `ProgramBoardViewModel.hasActiveSession` is true, the Program Board header shows an `End Session` control where the Start Session control normally appears.
- [ ] Activating the Program Board `End Session` control uses the same app session-ending path as the menu bar `End Session` item, including bridge stop request, active-session state reset, and overlay/recording cleanup.
- [ ] When no session is active, the existing Program Board `Start Session` control remains available and keeps launching the selected project/session as it does today.
- [ ] The control styling, sizing, hover help, and layout fit the existing compact Program Board header without crowding the `All` filter control.
- [ ] Project Board, Program Board ticket interactions, and ready-ticket dispatch behavior are not changed.
- [ ] Verification covers Codex and Claude session parity, or documents any intentional provider difference.
