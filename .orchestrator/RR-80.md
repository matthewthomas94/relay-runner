## Description

Clicking the Relay Runner Dock icon still does not open Settings for the user after the earlier Dock Settings work. Revisit the app activation path and make the Dock icon a reliable Settings entry point.

The intended behavior is: when Relay Runner is running and the user clicks its Dock icon, the Settings window opens or comes to the front. This should work whether Settings is already open, hidden behind other windows, or closed. Preserve the menu bar app behavior and do not introduce a normal main window.

## Acceptance criteria

- [ ] Clicking the Relay Runner Dock icon opens Settings when no Settings window is visible.
- [ ] Clicking the Dock icon brings an existing Settings window forward when one already exists.
- [ ] The menu bar Settings item continues to open the same Settings window.
- [ ] The app remains a menu bar app without an unwanted main/document window.
- [ ] Add or update focused tests around the app delegate/presenter behavior where possible, and add a manual verification note if the Dock click itself cannot be automated.
- [ ] Verify with `swift test --skip-update`.
