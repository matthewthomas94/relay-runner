## Description

Update the Workspace ticket UI in `Sources/relay-runner/Board/ProgramBoardOverlayView.swift` so board-lane ticket cards no longer show Edit controls or reserve an Edit hit area. Keep editing available from the opened ticket detail view. Use the existing Edit capsule styling as the visual baseline for the other actions inside the ticket: align shape, border radius, and core treatment, while preserving Delete as a distinct danger action. Update the focused presentation and overlay tests in `Tests/RelayRunnerTests/ProgramBoardStatusTests.swift` and `Tests/RelayRunnerTests/BoardOverlayScrollViewTests.swift` as needed.

- [ ] Ticket cards in board lanes do not display Edit buttons and do not reserve an Edit-button hit area.

- [ ] Other non-destructive action buttons inside the ticket detail or edit view use the same shape, corner radius, and core visual treatment as Edit.
- [ ] Delete retains its distinct danger color/treatment while using the same border radius as Edit.
- [ ] Focused Program Board presentation and overlay tests are updated to assert the new card and in-ticket behavior.
