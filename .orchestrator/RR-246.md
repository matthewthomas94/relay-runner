## Description

Update the Workspace ticket UI so ticket cards no longer show Edit buttons. Editing remains available from within the opened ticket. Restyle the other action buttons inside the ticket to share the current Edit button’s visual characteristics, including matching corner radius, while preserving Delete as a danger-styled action.

## Acceptance criteria

- [ ] Ticket cards in board lanes do not display Edit buttons.
- [ ] An Edit control is available inside the opened ticket view and retains the established Edit button styling.
- [ ] Other non-destructive action buttons inside the ticket use the same shape and core visual styling as Edit.
- [ ] Delete retains its distinct danger treatment while using the same border radius as Edit.
- [ ] Relevant UI tests or snapshots are updated, and the project’s focused verification passes.
