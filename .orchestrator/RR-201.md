## Description

Build the current `main` branch, including the completed RR-200 tutorial and the recently merged Relay response and ticket-card fixes, then install that exact build as the active `/Applications/Relay Runner.app`.

Use `./scripts/build-dmg.sh` as the source of truth. Do not hand-edit the installed app or any scripts inside its bundle. The build script should refresh an existing installed copy automatically; if no installed copy exists, use the generated `dist/RelayRunner.dmg` and its normal self-install flow.

This is a local rebuild and installation task only. Do not publish a release, upload artifacts, push branches, or change version numbers.

## Acceptance criteria

- [ ] Confirm the build starts from a clean current `main` containing the completed RR-200 work.
- [ ] Run `./scripts/build-dmg.sh` successfully without bypassing its normal bundling or signing steps.
- [ ] Verify the build produces `dist/Relay Runner.app`, `dist/RelayRunner.dmg`, and the Sparkle update zip reported by the script.
- [ ] Install the newly built app at `/Applications/Relay Runner.app`, using the script's refresh path when an installed copy already exists or the generated DMG's normal self-install path otherwise.
- [ ] Verify the installed app is the exact newly built bundle rather than a stale copy.
- [ ] Verify the installed bundle contains the packaged Python services and Relay MCP executables required by the app.
- [ ] Launch Relay Runner from `/Applications` and confirm it starts successfully as the menu-bar app.
- [ ] Record the build, signing/notarization, installation, bundle verification, and launch-smoke-test results in the ticket run log.
- [ ] Do not publish, upload, push, or make unrelated source changes.
