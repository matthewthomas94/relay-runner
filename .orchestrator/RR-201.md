## Description

Make the full-screen onboarding experience more restrained and visually concise. Reduce the shared onboarding hero typography from 48 points to 32 points and remove secondary explanatory subcopy from the onboarding screens.

Keep primary prompts, choices, action labels, progress or validation state, and actionable error or recovery messages intact. This preserves the recourse required when provider setup or another onboarding step cannot complete while removing nonessential descriptive copy.

## Acceptance criteria

- [ ] The shared onboarding hero typography renders at 32 points instead of 48 points across the cinematic intro, prompts, and session-controls tutorial.
- [ ] Standard onboarding screens no longer show nonessential secondary explanatory paragraphs beneath their primary prompt or action.
- [ ] Primary prompts, provider choices, buttons, validation state, and actionable failure or recovery messages remain visible and understandable.
- [ ] Existing onboarding layout and transitions are adjusted only as needed for the smaller hero type and removed subcopy, without introducing empty spacing intended for deleted content.
- [ ] Fresh first-run onboarding and manual “Redo Onboarding” use the same updated typography and copy treatment.
- [ ] Codex and Claude onboarding paths receive the same visual treatment.
- [ ] Automated tests cover the 32-point typography token and the absence of removed supporting copy from representative onboarding states.
