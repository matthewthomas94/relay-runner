The product policy is Parakeet on macOS 14 and Phonon 2 as the recommended English default on macOS 15+ once release validation passes, while retaining explicit Parakeet v3 multilingual choices and explicit rollback.

- [ ] Swift and Python agree on persisted identifiers, aliases, OS capability checks and defaults. Test fresh macOS 14 configuration retaining v2, the intended macOS 15+ Phonon default, existing v2/v3 configurations, legacy Whisper aliases and unknown identifiers.
- [ ] macOS 14 keeps its working Parakeet choice. Settings clearly label Phonon as English and requiring macOS 15+, and reject unsupported loading before I/O; v3 remains selectable for multilingual use.

- [ ] Record migration completion and the previous model for rollback. Explicit v3 choices and explicit user rollback are preserved; relaunch or a later OS upgrade cannot repeatedly override an explicit rollback.
- [ ] Model changes apply to the next recording. Active command capture, active notes and pending recovery tails keep their established model identity. Invalidate/recreate an idle cached note coordinator so the next note uses the current selection.
- [ ] Setup shows real download progress, compile/preparation phases, cancellation/failure and retry consistently in both entry points. Readiness does not claim the microphone. Keep the current eight-minute timeout unless measured evidence justifies a change.
- [ ] ConfigManagerTests, SetupRuntimeReadinessTests and tests/test_config.py pass with focused cases for OS selection, migration, failure, rollback and coordinator invalidation. Verify both command and note model identity after a safe settings change.
- [ ] Update docs/configuration.md, docs/architecture.md and setup/settings copy to describe OS support, English versus multilingual selection, retry and rollback. Preserve existing model caches.
- [ ] Record the precise local activation point for RR-416; this ticket does not activate the production automatic migration/default switch before release gates pass.
